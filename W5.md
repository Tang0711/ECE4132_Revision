## 1. Steady-State Error Formulation & The Final Value Theorem

```
                     r(t)        +   e(t)       +-------+        y(t)
                     ----------->(x)----------->|  L(s) |----+---->
                                  - ^           +-------+    |
                                    |                        |
                                    +------------------------+
```

### 1.1 The Definition of Steady-State Error

Steady-state error $e_{ss}$ is the discrepancy between the commanded reference input $r(t)$ and the actual plant output $y(t)$ after all transient natural modes have died out: $$e_{ss} \equiv \lim_{t \to \infty} e(t) = \lim_{t \to \infty} [r(t) - y(t)]$$

In the Laplace domain, the actuating error for a unity negative-feedback system with loop transfer function $L(s) = P(s)C(s)$ is given by: $$E(s) = R(s) - Y(s) = R(s) - L(s)E(s) \implies E(s) = \frac{1}{1 + L(s)} R(s)$$

### 1.2 Evaluation via the Final Value Theorem

The **Final Value Theorem (FVT)** enables the calculation of steady-state performance directly from the Laplace domain without computing inverse Laplace transforms: $$e_{ss} = \lim_{t \to \infty} e(t) = \lim_{s \to 0} s E(s) = \lim_{s \to 0} \frac{s R(s)}{1 + L(s)}$$

> **Strict Applicability Constraint**: The Final Value Theorem is valid **if and only if all poles of $s E(s)$ reside strictly in the open left-half of the complex plane (OLHP)**. If the closed-loop system is unstable, or if $s E(s)$ has poles on the imaginary axis or in the right-half plane, the time-domain signal $e(t)$ does not converge to a constant value, rendering the algebraic limit meaningless.

## 2. System Type and Static Error Constants

Steady-state performance depends on the interaction between two characteristics:

1. **The mathematical form of the test input** $R(s)$.
2. **The number of pure open-loop integrators** contained in the forward loop $L(s)$.

### 2.1 Standard Reference Test Inputs

To quantify tracking capabilities, systems are tested against three polynomial test waveforms:

1. **Unit Step Input (Position Command)**: $$r(t) = 1(t) \iff R(s) = \frac{1}{s}$$ Represents an instantaneous setpoint change to a fixed target.
2. **Unit Ramp Input (Velocity Command)**: $$r(t) = t \cdot 1(t) \iff R(s) = \frac{1}{s^2}$$ Represents a target moving with constant velocity.
3. **Unit Parabolic Input (Acceleration Command)**: $$r(t) = \frac{1}{2}t^2 \cdot 1(t) \iff R(s) = \frac{1}{s^3}$$ Represents a target moving with constant acceleration.

### 2.2 System Type Definition

Express the open-loop transfer function in factored pole-zero form: $$L(s) = P(s)C(s) = \frac{K \prod_{j=1}^{m} (s + z_j)}{s^N \prod_{i=1}^{n-N} (s + p_i)}$$ where $-z_j$ and $-p_i$ represent non-zero finite zeros and poles.

- **System Type**: The integer exponent $N$ representing the **multiplicity of pure poles at the origin ($s = 0$)** in $L(s)$.
    - $N = 0 \implies$ **Type-0 System** (no integrators in the loop).
    - $N = 1 \implies$ **Type-1 System** (one pure integrator in the loop).
    - $N = 2 \implies$ **Type-2 System** (two pure integrators in the loop).

---

### 2.3 Static Error Constants

By substituting the standard test inputs into the Final Value Theorem, three static figures of merit are defined:

#### 1. Position Error Constant ($K_p$)

Evaluated for a unit step reference $R(s) = 1/s$: $$e_{ss,\text{step}} = \lim_{s \to 0} \frac{s \left(\frac{1}{s}\right)}{1 + L(s)} = \frac{1}{1 + \lim_{s \to 0} L(s)} \equiv \frac{1}{1 + K_p}$$ $$K_p \equiv \lim_{s \to 0} L(s)$$

#### 2. Velocity Error Constant ($K_v$)

Evaluated for a unit ramp reference $R(s) = 1/s^2$: $$e_{ss,\text{ramp}} = \lim_{s \to 0} \frac{s \left(\frac{1}{s^2}\right)}{1 + L(s)} = \lim_{s \to 0} \frac{1}{s + sL(s)} = \frac{1}{\lim_{s \to 0} s L(s)} \equiv \frac{1}{K_v}$$ $$K_v \equiv \lim_{s \to 0} s L(s)$$ _(Note: $e_{ss,\text{ramp}}$ is a positional tracking offset measured in output units, not an error in velocity)._

#### 3. Acceleration Error Constant ($K_a$)

Evaluated for a unit parabolic reference $R(s) = 1/s^3$: $$e_{ss,\text{parabola}} = \lim_{s \to 0} \frac{s \left(\frac{1}{s^3}\right)}{1 + L(s)} = \lim_{s \to 0} \frac{1}{s^2 + s^2L(s)} = \frac{1}{\lim_{s \to 0} s^2 L(s)} \equiv \frac{1}{K_a}$$ $$K_a \equiv \lim_{s \to 0} s^2 L(s)$$

---

Evaluating $K_p, K_v, K_a$ as $s \to 0$ across system types generates the following relationships:

## 3. Disturbance Rejection and Non-Unity Feedback

### 3.1 Steady-State Error Caused by Input Load Disturbances

Real-world systems are subjected to external load disturbances $D(s)$ (e.g., wind gusts on an antenna, payload changes on a robotic arm, or road slope torque on a vehicle):

```
                                      D(s) (Load Disturbance)
                                        |
                 R(s)    +    E(s)    +---+    +       +-------+        Y(s)
                 ------->(x)--------->|C(s)|--> (x)--->|  P(s) |----+---->
                          - ^         +---+     +      +-------+    |
                            |                                       |
                            +---------------------------------------+
```

Using superposition, the error transfer function relating reference $R(s)$ and disturbance $D(s)$ to tracking error $E(s) = R(s) - Y(s)$ is: $$E(s) = \frac{1}{1 + C(s)P(s)} R(s) - \frac{P(s)}{1 + C(s)P(s)} D(s)$$

Applying the Final Value Theorem for a constant step disturbance $D(s) = \frac{D_0}{s}$ with zero reference ($R(s) = 0$): $$e_{D}(\infty) = -\lim_{s \to 0} s \left[ \frac{P(s)}{1 + C(s)P(s)} \cdot \frac{D_0}{s} \right] = -\frac{P(0)}{1 + C(0)P(0)} D_0$$

- **Type-0 Control (Finite $C(0) = K_p$)**: A constant disturbance induces a permanent steady-state output offset: $e_D(\infty) = -\frac{P(0)}{1 + K_p P(0)} D_0 \ne 0$.
- **Integral Control ($C(s)$ contains $1/s$)**: As $s \to 0$, the controller gain $|C(0)| \to \infty$. Substituting this into the disturbance error equation: $$e_{D}(\infty) = -\lim_{s \to 0} \frac{s P(s)}{s + s C(s)P(s)} D_0 = -\frac{P(0)}{\infty} D_0 = 0$$ An integrator situated in the controller **completely eliminates steady-state offsets caused by constant step load disturbances**.

### 3.2 Non-Unity Feedback Systems

When the feedback path contains measurement sensor dynamics $H(s) \ne 1$, the actuating signal $E_a(s) = R(s) - H(s)Y(s)$ is no longer equal to the physical tracking error $E(s) = R(s) - Y(s)$.

```
                 R(s)    +    Ea(s)   +-------+   Y(s)
                 ------->(x)--------->|  G(s) |----+---->
                          - ^         +-------+    |
                            |         +-------+    |
                            +---------|  H(s) |<---+
                                      +-------+
```

To compute steady-state error using standard static error constants, convert the loop into an **algebraically equivalent unity-feedback system**: $$T(s) = \frac{G(s)}{1 + G(s)H(s)} \equiv \frac{G_e(s)}{1 + G_e(s)}$$ Solving for the equivalent forward transfer function $G_e(s)$: $$G_e(s) = \frac{G(s)}{1 + G(s)[H(s) - 1]}$$ Once $G_e(s)$ is established, determine the true system type and evaluate $K_p, K_v, K_a$ as usual.

## 4. Proportional-Integral (PI) Control: Mechanism & Dynamics

To eliminate steady-state error without requiring impractical infinite proportional gains, an active integrator is placed in the forward loop.

```
                            +---------------+
                            |     Ki / s    | (Integral Path)
                     +----->|  (Accumulator)|------+
                     |      +---------------+      |
     e(t)            |                             v   +
   --------->(x)-----+                             (x)---> u(t)
              |      |      +---------------+      ^   +
              |      +----->|      Kp       |------+
              |             | (Proportional)|
              |             +---------------+
              v
     Persistent Error Area
```

### 4.1 Mathematical Formulation

The continuous-time control law and corresponding transfer function are: $$u(t) = K_p e(t) + K_i \int_{0}^{t} e(\tau) , d\tau \iff C(s) = K_p + \frac{K_i}{s} = \frac{K_p s + K_i}{s}$$

Factoring out the proportional gain: $$C(s) = K_p \left( \frac{s + \frac{K_i}{K_p}}{s} \right) = K_p \left( \frac{s + z_i}{s} \right)$$

- **Pole at $s = 0$**: Adds an open-loop integrator, increasing the system type by 1 (e.g., converting a Type-0 plant into a Type-1 closed-loop system).
- **Zero at $s = -z_i = -K_i / K_p$**: Placed in the left-half plane to balance the destabilising phase lag contributed by the integrator pole.

### 4.2 Physical Intuition: The Error Accumulator

If a non-zero steady-state tracking error $e_{ss} \ne 0$ were to persist under constant reference and load conditions, the integral term $K_i \int_0^t e(\tau) d\tau$ would integrate a constant over time, ramping $u(t)$ towards $\pm \infty$. Because physical variables in a stable closed-loop cannot grow without bound, the loop can only reach equilibrium when the error is driven to zero: $$e_{ss} = 0$$ The integrator stores the exact steady-state bias voltage/torque required to sustain the output at the setpoint, freeing the proportional error from needing an offset.

---

### 4.3 Root Locus Dynamics and Transient Trade-offs

While a PI controller eliminates steady-state step error, it alters transient dynamics:

```
                     Effect of PI Controller on the Root Locus
                                      jω
                                       |
                       Dominant Pole   |
                            x          |
                            |          |
                            |          |
            -zi             |          |
      -------o--------------x----------x--------------------------> σ
           PI Zero          ^        Origin
                      Extra Closed-   (Pole at 0)
                        Loop Pole
```

1. **Increased System Order**: Adding an integrator pole increases the closed-loop system order by one (e.g., a second-order plant becomes a third-order system).
2. **Phase Lag & Reduced Stability Margins**: The pole at $s = 0$ contributes $-90^\circ$ of phase lag across low frequencies, pushing the root locus rightward toward the imaginary axis and increasing transient overshoot.
3. **Pole-Zero Dipole & Slow Settling Tails**: To preserve the transient response shaped during earlier design stages, the PI zero $z_i$ is placed **very close to the origin** (e.g., $z_i \in [0.01, 0.1]$).
    - This forms a **pole-zero dipole** near $s = 0$.
    - The pole at $0$ and zero at $-z_i$ contribute nearly equal and opposite angles to the dominant high-frequency poles, leaving their location virtually unaltered.
    - _Trade-off_: A closed-loop pole is trapped along the real axis between $0$ and $-z_i$. Although its residue is small due to near cancellation by the zero, it decays slowly with time constant $\tau = 1/z_i$, causing a long "tail" in the step response that lengthens the $2\%$ settling time.

## 5. Passive Lag Compensation: Practical Approximation to PI Control

### 5.1 Motivation for Lag Compensation

An ideal PI controller requires active electronics (operational amplifiers with low input bias currents and high-quality capacitors) or digital computing hardware to implement the pure integrator. In cost-sensitive or passive analog applications, a **Phase-Lag Compensator** provides a passive approximation.

### 5.2 Transfer Function & Geometric Placement

A lag compensator places its pole off the origin on the negative real axis, with its zero located to the left of the pole: $$C_{\text{lag}}(s) = K_c \frac{s + z_c}{s + p_c} \quad \text{where } z_c > p_c > 0$$

```
                             Lag Compensator Pole-Zero Map
                                       jω
                                        |
                 Zero -zc       Pole -pc|
   -----------------o--------------x----+--------------------------> σ
                                        | 0
                    <--------------|
                        zc > pc (Phase Lag)
```

Factoring into time-constant form: $$C_{\text{lag}}(s) = \hat{K}_c \frac{T s + 1}{\beta T s + 1} = \frac{K_c}{\beta} \frac{s + \frac{1}{T}}{s + \frac{1}{\beta T}}$$ where: $$\beta = \frac{z_c}{p_c} > 1, \qquad T = \frac{1}{z_c}$$

### 5.3 Low-Frequency Gain Boost & Minimal Transient Distortion

1. **Low-Frequency DC Gain Boost**: Evaluating the compensator gain as $s \to 0$: $$C_{\text{lag}}(0) = K_c \frac{z_c}{p_c} = K_c \beta$$ The lag compensator multiplies the static error constant ($K_p$ or $K_v$) by the factor $\beta = \frac{z_c}{p_c}$, reducing steady-state error by a factor of $\beta$: $$K_{v,\text{new}} \approx \beta \cdot K_{v,\text{old}} \implies e_{ss,\text{new}} \approx \frac{e_{ss,\text{old}}}{\beta}$$
2. **Transient Isolation Principle**: By choosing $p_c$ and $z_c$ very close to each other near the origin (e.g., $p_c = 0.005, z_c = 0.05 \implies \beta = 10$), the angle contribution to the dominant closed-loop poles $s_0$ is minimal: $$\theta_{\text{lag}} = \angle(s_0 + z_c) - \angle(s_0 + p_c) \approx 0^\circ \quad (\text{typically } < 2^\circ \text{ to } 5^\circ)$$ Because the phase contribution is negligible, the compensated root locus passes through the existing dominant poles without altering transient response speed or damping.

## 6. Proportional-Integral-Derivative (PID) Control: Dual Compensation

### 6.1 The Complete Three-Term PID Controller

A PID controller combines derivative action (transient shaping and damping) with integral action (steady-state error elimination): $$u(t) = K_p e(t) + K_i \int_{0}^{t} e(\tau) , d\tau + K_d \frac{de(t)}{dt}$$ $$C(s) = K_p + \frac{K_i}{s} + K_d s = \frac{K_d s^2 + K_p s + K_i}{s}$$

```
                                  +---------------+
                                  |     Kd s      | (Derivative: Future Error)
                           +----->|  (Damping)    |------+
                           |      +---------------+      |
                           |                             v   +
           e(t)            |      +---------------+      (x)
         --------->(x)-----+----->|      Kp       |-----> +  +
                    |      |      |  (Present)    |         (x)---> u(t)
                    |      |      +---------------+         ^   +
                    |      |                                |
                    |      |      +---------------+         |
                    |      +----->|     Ki / s    |---------+
                    |             | (Past Accum.) |
                    v             +---------------+
         Dual Performance Tuning
```

Factoring the numerator quadratic: $$C(s) = K_d \frac{(s + z_1)(s + z_2)}{s}$$

- **Pole at the origin ($s = 0$)**: Provides integral action to eliminate steady-state error.
- **Two Zeros ($-z_1, -z_2$)**:
    - One zero acts as the **integral zero**, placed near the origin to preserve low-frequency loop properties.
    - The second zero acts as the **derivative zero**, placed deeper in the left-half plane to inject phase lead, pull the root locus leftward, and improve transient damping.

### 6.2 Arbitrary Second-Order Pole Placement

A standard prototype second-order plant possesses two poles. Cascading it with a PID controller produces a third-order closed-loop system with three characteristic coefficients: $$P(s) = \frac{1}{s(s + a)} \implies \Delta(s) = s^2(s + a) + (K_d s^2 + K_p s + K_i) = s^3 + (a + K_d)s^2 + K_p s + K_i = 0$$

Because the three controller gains ($K_p, K_i, K_d$) map independently to the three characteristic polynomial coefficients, **all three closed-loop poles can be assigned arbitrarily**. Designers can place two dominant complex poles for target transient performance ($\zeta, \omega_n$) and place the third real pole far into the OLHP to make it negligible.

## 7. Worked Design Example: PID Controller via Matched Pole Placement

Consider the position control of an inertia-damper system governed by: $$P(s) = \frac{1}{s(s + 2)}$$ **Design Specifications**:

1. **Steady-State Accuracy**: Zero steady-state error for a unit step input ($e_{ss} = 0$).
2. **Dominant Transient Dynamics**: Damping ratio $\zeta \approx 0.707$ and natural frequency $\omega_n = \sqrt{2} \approx 1.414\text{ rad/s}$, corresponding to a dominant complex pole pair at: $$s_{1,2} = -1 \pm j1$$
3. **Non-Dominant Pole Separation**: The third closed-loop pole must be placed at $s_3 = -4$ (four times farther from the imaginary axis than the dominant real part).

### Step 1: Formulate the Target Characteristic Polynomial

The desired closed-loop characteristic equation is formed by expanding the three target pole factors: $$\Delta_{\text{desired}}(s) = (s - s_3)(s - s_1)(s - s_2) = (s + 4)\left( (s + 1)^2 + 1^2 \right)$$ $$\Delta_{\text{desired}}(s) = (s + 4)(s^2 + 2s + 2) = s^3 + 2s^2 + 2s + 4s^2 + 8s + 8$$ $$\Delta_{\text{desired}}(s) = s^3 + 6s^2 + 10s + 8$$

### Step 2: Formulate the Closed-Loop Characteristic Polynomial with PID

Using a standard PID controller $C(s) = K_p + \frac{K_i}{s} + K_d s = \frac{K_d s^2 + K_p s + K_i}{s}$: $$L(s) = P(s)C(s) = \frac{K_d s^2 + K_p s + K_i}{s^2(s + 2)}$$ The closed-loop characteristic equation is $1 + L(s) = 0$: $$s^2(s + 2) + (K_d s^2 + K_p s + K_i) = 0$$ $$\Delta(s) = s^3 + (2 + K_d)s^2 + K_p s + K_i = 0$$

### Step 3: Match Coefficients to Solve for Controller Gains

Equating corresponding powers of $s$ between $\Delta(s)$ and $\Delta_{\text{desired}}(s)$:

1. **For $s^2$**: $$2 + K_d = 6 \implies \mathbf{K_d = 4}$$
2. **For $s^1$**: $$K_p = 10 \implies \mathbf{K_p = 10}$$
3. **For $s^0$**: $$K_i = 8 \implies \mathbf{K_i = 8}$$

The designed PID controller transfer function is: $$C(s) = 10 + \frac{8}{s} + 4s = \frac{4s^2 + 10s + 8}{s}$$

### Step 4: Verify Steady-State Performance

- The open-loop loop transfer function is: $$L(s) = \frac{4s^2 + 10s + 8}{s^2(s + 2)}$$
- Because $L(s)$ contains a factor of $s^2$ in its denominator, the loop is a **Type-2 system**.
- For a unit step input: $e_{ss,\text{step}} = 0$.
- For a unit ramp input: $K_v = \lim_{s \to 0} s L(s) = \infty \implies e_{ss,\text{ramp}} = 0$.
- For a unit parabolic input: $$K_a = \lim_{s \to 0} s^2 L(s) = \lim_{s \to 0} \frac{4s^2 + 10s + 8}{s + 2} = \frac{8}{2} = 4$$ $$e_{ss,\text{parabola}} = \frac{1}{K_a} = \frac{1}{4} = 0.25$$
