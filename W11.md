### Core Concepts & Formulations

#### Definition of the Nyquist Plot

The **Nyquist plot** of a loop transfer function $L(s) = P(s)C(s)$ is a parametric polar plot in the complex plane tracing the real and imaginary parts of $L(s)$ as the complex variable $s$ traverses a specialized closed boundary known as the **Nyquist contour**. It integrates magnitude $|L(j\omega)|$ and phase angle $\angle L(j\omega)$ into a single continuous curve, serving as the 2D polar counterpart of the dual Bode diagrams.

```
                 Nyquist s-Plane Contour (Γ)                     Nyquist Plot Plane L(s)
                            jω                                             Im L(s)
                             ^                                                ^
                        +jR  |                                                |
                             |  )                                             |     /---\
                             |   \                                            |    /     \
                             |    \                                     -1    |   |       |
                        +jr  |     |  Outer Arc:                     ----+----+---+-------+---> Re L(s)
                             +--\  |  s = R e^(jθ)                        |   |    \     /
                             |   | |  R -> ∞, θ: +90° -> -90°             |    \---/
                        -jr  +--/  |                                      |
                             |     |                                      v
                             |    /   Detour around s=0:
                             |   /    s = r e^(jθ), r -> 0
                        -jR  |  )     θ: -90° -> +90°
                             +-------------------------> σ
```

_(Left: The Nyquist D-contour enclosing the right-half plane. Right: Mapping into the complex loop transfer plane)._

#### The Nyquist D-Contour ($\Gamma$)

To determine whether any closed-loop poles reside in the unstable right-half plane ($\text{Re}(s) > 0$), we define a closed path $\Gamma$ traversed in the **clockwise direction**:

1. **Positive Imaginary Axis ($C_1$):** Directed path along $s = +j\omega$ as $\omega$ ascends from $0^+$ to $+R$ (where $R \to \infty$).
2. **Infinite Semicircular Arc ($C_3$):** Semicircle traversing the entire RHP given by $s = R e^{j\theta}$, with radius $R \to \infty$ and angle $\theta$ sweeping clockwise from $+90^\circ$ to $-90^\circ$.
3. **Negative Imaginary Axis ($C_2$):** Directed path along $s = -j\omega$ descending from $-R$ back to $0^-$.
4. **Infinitesimal Detours Around Imaginary Singularities ($C_4$):** If $L(s)$ possesses poles on the imaginary axis (e.g., pure integrators at $s = 0$ or undamped resonant poles at $\pm j\omega_0$), the contour bypasses them into the RHP along an infinitesimal semicircular arc: $$s = r e^{j\theta}, \quad r \to 0, \quad \theta \in [-90^\circ, +90^\circ] \text{ (clockwise)} \quad$$

#### Cauchy’s Principle of the Argument

Let $F(s)$ be a single-valued, rational complex function that is analytic everywhere on and within a closed, simple clockwise contour $\Gamma$, except at a finite number of isolated poles. As $s$ traces $\Gamma$ in the clockwise direction, the mapped locus $F(\Gamma)$ encircles the origin in the complex $F$-plane $N_0$ times in the clockwise direction: $$N_0 = Z_F - P_F \quad$$ where:

- $Z_F$ is the number of **zeros** of $F(s)$ enclosed inside contour $\Gamma$.
- $P_F$ is the number of **poles** of $F(s)$ enclosed inside contour $\Gamma$.

_Mathematical Intuition:_ Any factor $(s - z_i)$ corresponding to an enclosed zero rotates by a full net angle of $-360^\circ$ (clockwise) as $s$ completes its circuit around $\Gamma$. Any enclosed pole factor $(s - p_j)^{-1}$ contributes an opposite rotation of $+360^\circ$ (counter-clockwise). Singularities outside the contour undergo zero net angular change.

#### Translating from Origin Encirclement to Critical Point $-1$

The closed-loop transfer function under negative unity feedback is: $$G_{cl}(s) = \frac{L(s)}{1 + L(s)} \quad$$ Closed-loop poles are precisely the roots of the characteristic equation $1 + L(s) = 0$. Define the auxiliary function $F(s) = 1 + L(s)$:

- The **zeros of $F(s)$** are the roots of $1 + L(s) = 0$, which are the **closed-loop poles** of the feedback system.
- The **poles of $F(s)$** are identical to the poles of $L(s)$, which are the **open-loop poles** of the system.

Because $F(s) = 1 + L(s)$ is simply $L(s)$ shifted to the right by $+1$ unit in the complex plane, mapping $F(s)$ relative to the origin $0 + j0$ is identical to mapping $L(s)$ relative to the **critical point** $-1 + j0$: $$F(s) = 0 \iff L(s) = -1 \quad$$

## 2. The Nyquist Stability Criterion

### Revision Checklist

- [ ] **State the general Nyquist stability formula** $Z = N + P$ (defining the sign convention for clockwise vs. counter-clockwise encirclements).
- [ ] **Define the variable meanings**: $Z$ (unstable closed-loop poles), $P$ (unstable open-loop poles), and $N$ (clockwise encirclements of $-1$).
- [ ] **State the condition for closed-loop stability** ($Z = 0 \iff N = -P$).
- [ ] **Formulate the simplified criterion** for open-loop stable systems ($P = 0 \implies N = 0$).
- [ ] **Analyze unstable open-loop systems** ($P > 0$) requiring active counter-clockwise encirclements to achieve stability.

---

### Core Concepts & Formulations

#### The General Nyquist Stability Formula

Evaluating the open-loop transfer function $L(s)$ along the clockwise Nyquist contour $\Gamma$ yields the fundamental stability equation: $$Z = N + P \quad$$ where:

- **$P \ge 0$:** The number of open-loop poles of $L(s)$ lying strictly in the open right-half plane ($\text{Re}(p) > 0$).
- **$N$:** The **net number of clockwise encirclements** of the critical point $-1 + j0$ made by the locus of $L(s)$. Counter-clockwise encirclements count as negative ($N < 0$).
- **$Z \ge 0$:** The number of closed-loop poles of the feedback system lying strictly in the open right-half plane.

#### Stability Condition

To achieve an internally stable closed-loop system, there must be **zero closed-loop poles in the right-half plane** ($Z = 0$): $$Z = 0 \iff N = -P \quad$$

> **The General Nyquist Stability Criterion:** A feedback control system is closed-loop stable if and only if the Nyquist plot of $L(s)$ encircles the critical point $-1 + j0$ **counter-clockwise exactly $P$ times**, where $P$ is the number of open-loop right-half-plane poles of $L(s)$.

```
               Open-Loop System Characterization: Count RHP Poles (P)
                                         |
                       +-----------------+-----------------+
                       |                                   |
                 Case 1: P = 0                       Case 2: P > 0
              (Open-Loop Stable)                  (Open-Loop Unstable)
                       |                                   |
             Requirement for Stability:          Requirement for Stability:
                   N = 0                               N = -P
             Zero Encirclements of -1            Must encircle -1 exactly
                       |                         P times COUNTER-CLOCKWISE
                       v                                   |
         Any encirclement => UNSTABLE                      v
                                             Fails to encircle P times CCW => UNSTABLE
```

_(Decision hierarchy for the Nyquist Stability Criterion)._

#### The Simplified Criterion ($P = 0$)

When the plant and controller have no poles in the open RHP ($P = 0$), the stability condition collapses to: $$N = 0 \quad$$ The closed-loop system is stable if and only if the Nyquist plot of $L(s)$ exhibits **zero net encirclements of $-1 + j0$**. Any encirclement ($N > 0$) indicates closed-loop instability ($Z = N$).

#### Open-Loop Unstable Systems ($P > 0$)

When an open-loop plant is unstable ($P > 0$), stability **demands** that the Nyquist plot actively encircle the critical point $-1$ in the counter-clockwise direction.

- _Example (Inverted Pendulum):_ Consider an open-loop unstable plant $P(s) = \frac{1}{(s+1)(s-1)}$ with $P = 1$ (unstable pole at $s = +1$) stabilized by a PD compensator $C(s) = K(s+2)$. The loop transfer function is: $$L(s) = \frac{K(s+2)}{(s+1)(s-1)}, \quad P = 1 \quad$$ For closed-loop stability, we require $Z = N + P = 0 \implies N = -1$ (one net counter-clockwise encirclement). Evaluating the real-axis intercept shows that for $K < 0.5$, the plot fails to encircle $-1$ ($N = 0 \implies Z = 1$, unstable). For $K > 0.5$, the locus expands to enclose $-1$ in the counter-clockwise direction ($N = -1 \implies Z = 0$), stabilizing the physical inverted pendulum.

### Step-by-Step Construction Procedure

```
                     +---------------------------------------------+
                     | Step 1: Positive Imaginary Axis             |
                     | Evaluate L(jω) for ω: 0+ -> +∞              |
                     | (Corresponds to polar plot of Bode response)|
                     +----------------------|----------------------+
                                            v
                     +---------------------------------------------+
                     | Step 2: Infinite Outer Arc (R -> ∞)         |
                     | Evaluate L(R*e^(jθ)) for θ: +90° -> -90°    |
                     | (Maps to origin 0 if strictly proper)       |
                     +----------------------|----------------------+
                                            v
                     +---------------------------------------------+
                     | Step 3: Negative Imaginary Axis             |
                     | Plot complex conjugate L(-jω) = L*(jω)      |
                     | (Exact mirror reflection across real axis)  |
                     +----------------------|----------------------+
                                            v
                     +---------------------------------------------+
                     | Step 4: Detours Around Poles on jω-Axis     |
                     | Evaluate L(r*e^(jθ)) for r -> 0             |
                     | (Sweeps large arcs of radius ∞ at origin)   |
                     +---------------------------------------------+
```

_(The four-step algorithmic workflow for plotting Nyquist diagrams)._

#### 1. Positive Imaginary Axis ($\omega: 0^+ \to +\infty$)

Substitute $s = j\omega$ directly into $L(s)$: $$L(j\omega) = \text{Re}[L(j\omega)] + j \text{Im}[L(j\omega)] = |L(j\omega)| e^{j \angle L(j\omega)} \quad$$ This matches the polar representation of the system’s steady-state frequency response.

- **Low-Frequency Anchor ($\omega \to 0^+$):** For a type-0 system, $L(j0) = K_{\text{dc}}$ on the positive real axis.
- **High-Frequency Termination ($\omega \to +\infty$):** If the relative degree $n - m \ge 1$, $|L(j\omega)| \to 0$, and the locus spirals into the origin at an asymptotic approach angle of $-(n - m) \times 90^\circ$.

#### 2. Infinite Semicircular Arc ($R \to \infty$)

For points along $s = R e^{j\theta}$ with $\theta$ sweeping from $+90^\circ$ through $0^\circ$ to $-90^\circ$: $$\lim_{R \to \infty} L(R e^{j\theta}) = \lim_{R \to \infty} \frac{b_0 R^m e^{jm\theta}}{R^n e^{jn\theta}} = \lim_{R \to \infty} \frac{b_0}{R^{n-m}} e^{-j(n-m)\theta} \quad$$ For any **strictly proper** system ($n > m$), the magnitude becomes identically zero ($0 \cdot e^{-j(n-m)\theta} = 0$), mapping the entire infinite semicircle of the $s$-plane into a single static point at the origin of the $L(s)$-plane.

#### 3. Negative Imaginary Axis ($\omega: -\infty \to 0^-$)

Because physical transfer functions have real polynomial coefficients, the frequency response satisfies Hermitian symmetry: $$L(-j\omega) = L^*(j\omega) = \text{Re}[L(j\omega)] - j \text{Im}[L(j\omega)] \quad$$ The negative frequency locus is the **exact mirror image** of the positive frequency plot reflected across the horizontal real axis. The orientation arrows continue in the same continuous sequence.

#### 4. Handling Poles on the Imaginary Axis ($s = 0$)

If $L(s)$ possesses a pole at the origin of multiplicity $m$ ($L(s) = \frac{K}{s^m (Ts + 1)\dots}$), substituting the semicircular detour $s = r e^{j\theta}$ (with $r \to 0$ and $\theta$ sweeping from $-90^\circ$ to $+90^\circ$ clockwise) yields: $$\lim_{r \to 0} L(r e^{j\theta}) \approx \frac{K}{r^m e^{jm\theta}} = \left(\lim_{r \to 0} \frac{K}{r^m}\right) e^{-jm\theta} = \infty \cdot e^{-jm\theta} \quad$$

- **For a single integrator ($m = 1$):** As $\theta$ moves clockwise from $-90^\circ \to 0^\circ \to +90^\circ$, the phase of $L(s)$ rotates counter-clockwise from $+90^\circ \to 0^\circ \to -90^\circ$ along an arc of infinite radius in the right half of the $L(s)$-plane.
- **For a double integrator ($m = 2$):** The infinite arc sweeps through $-2 \times 180^\circ = -360^\circ$.

#### Analytical Determination of Real-Axis Crossings

To determine whether the locus encircles the critical point $-1$, find the exact crossing point on the real axis:

1. Separate $L(j\omega)$ into analytical real and imaginary components: $$L(j\omega) = u(\omega) + j v(\omega) \quad$$
2. Set the imaginary component to zero to solve for the **phase crossover frequency** $\omega_{pc}$: $$v(\omega_{pc}) = \text{Im}[L(j\omega_{pc})] = 0 \quad$$
3. Substitute $\omega_{pc}$ back into the real part to find the intercept value $L(j\omega_{pc}) = u(\omega_{pc})$. The critical gain threshold is $K_{\text{crit}} = \frac{1}{|u(\omega_{pc})|}$.

## 4. Stability Margins: Gain Margin, Phase Margin, and Stability Margin

### Revision Checklist

- [ ] **Define Phase Crossover Frequency ($\omega_{pc}$)** where $\angle L(j\omega_{pc}) = -180^\circ$.
- [ ] **Define Gain Margin ($g_m$)** mathematically and geometrically on the Nyquist plot and Bode diagram.
- [ ] **Define Gain Crossover Frequency ($\omega_{gc}$)** where $|L(j\omega_{gc})| = 1$ ($0\text{ dB}$).
- [ ] **Define Phase Margin ($\phi_m$)** mathematically and geometrically as the angle shortfall to $-180^\circ$.
- [ ] **Define the Stability Margin ($s_m$)** as the minimum vector distance to $-1$: $s_m = \min_\omega |1 + L(j\omega)|$.
- [ ] **State the analytical lower bounds** relating $s_m$ to $g_m$ and $\phi_m$.
- [ ] **Explain why large $g_m$ and $\phi_m$ do not guarantee a large stability margin $s_m$**.

### Core Concepts & Formulations

```
                            Im L(jω)
                               ^
                               |
                        +1     |   Unit Circle (|L| = 1)
                             \ | /
                              \|/
      -1         -1/gm         |
      -+-----------*-----------+-------------------------> Re L(jω)
        \         / \          |
         \  sm   /   \         |
          \     /     \        |
           \   /       * L(jωgc)
            \ v       /
             *-------+
            L(jωms)   \  Phase Margin: φm = 180° + ∠L(jωgc)

```

_(Geometric definition of Gain Margin $g_m$, Phase Margin $\phi_m$, and Stability Margin $s_m$ on the Nyquist plot)._

#### 1. Gain Margin ($g_m$)

The **Gain Margin** is the factor by which open-loop gain can be increased before the feedback system becomes unstable: $$\angle L(j\omega_{pc}) = -180^\circ = -\pi \text{ rad} \implies g_m = \frac{1}{|L(j\omega_{pc})|} \quad$$ Expressed in decibels on a Bode plot: $$GM_{\text{dB}} = 20\log_{10}(g_m) = -20\log_{10}|L(j\omega_{pc})| \quad$$

- **Geometric Interpretation:** The Nyquist curve crosses the negative real axis at the coordinate $(-1/g_m, 0)$. Multiplying the loop by $g_m$ expands the curve radially until the intercept point touches $-1 + j0$.

#### 2. Phase Margin ($\phi_m$)

The **Phase Margin** is the additional phase lag that can be introduced at the gain crossover frequency before the closed-loop system reaches the boundary of instability: $$|L(j\omega_{gc})| = 1 \quad (0\text{ dB}) \implies \phi_m = 180^\circ + \angle L(j\omega_{gc}) \quad$$

- **Geometric Interpretation:** The angle measured from the negative real axis ($-180^\circ$) to the radial line connecting the origin to the point where the Nyquist plot intersects the unit circle ($|L| = 1$).
- **Time-Delay Robustness:** A pure transport delay $e^{-s\tau}$ adds phase lag $-\omega \tau$ without altering magnitude. The maximum tolerable loop latency before instability occurs is: $$\tau_{\text{max}} = \frac{\phi_m}{\omega_{gc}} \quad (\phi_m \text{ in radians})$$

#### 3. Stability Margin ($s_m$)

The **Stability Margin** (modulus margin) is the shortest Euclidean distance from the complete Nyquist locus $L(j\omega)$ to the critical instability point $-1 + j0$: $$s_m = \min_{-\infty < \omega < +\infty} |1 + L(j\omega)| \quad$$ Geometrically, a circle centered at $-1$ with radius $s_m$ just touches the Nyquist locus without being penetrated by it.

#### Quantitative Interrelationships

A large stability margin guarantees healthy gain and phase margins via the fundamental inequalities: $$g_m \ge \frac{1}{1 - s_m}, \quad \phi_m \ge 2 \arcsin\left(\frac{s_m}{2}\right) \quad$$

- _Example Bounds:_
    - If $s_m = 0.5 \implies g_m \ge \frac{1}{1 - 0.5} = 2 \ (6.02\text{ dB}), \quad \phi_m \ge 2\arcsin(0.25) \approx 28.96^\circ$.
    - If $s_m = 0.8 \implies g_m \ge \frac{1}{1 - 0.8} = 5 \ (13.98\text{ dB}), \quad \phi_m \ge 2\arcsin(0.4) \approx 47.16^\circ$.

#### Why Classical Margins Can Fail

Classical margins evaluate perturbations independently along specific coordinate cuts: $g_m$ checks only real-axis crossings at $-180^\circ$, while $\phi_m$ checks only the unit circle at $0\text{ dB}$.

- **The Vulnerability (The "Bulge" Phenomenon):** Consider a resonant plant transfer function: $$L(s) = \frac{0.38(s^2 + 0.1s + 0.55)}{s(s + 1)(s^2 + 0.06s + 0.5)} \quad$$ Evaluating classical metrics yields an exceptionally large gain margin ($g_m = 266 \approx 48.5\text{ dB}$) and a healthy phase margin ($\phi_m = 70^\circ$). However, between $\omega_{gc}$ and $\omega_{pc}$, the Nyquist plot develops an internal loop that passes within $0.27$ units of the critical point ($s_m = 0.27$). A simultaneous modest gain increase combined with a minor phase lag pushes the loop around $-1$, causing unexpected closed-loop instability. **Checking $s_m$ protects against these hidden multi-variable failures**.

## 5. Geometric and Algebraic Link to the Sensitivity Function $S(s)$

### Revision Checklist

- [ ] **Relate the stability margin $s_m$ directly to peak sensitivity** $M_s$: $s_m = 1/M_s$.
- [ ] **Interpret circles centered at $-1$** in the Nyquist plane as contours of constant sensitivity magnitude.
- [ ] **State the standard engineering design constraint** on peak sensitivity ($M_s < 1.5 - 2.0$, ensuring $s_m > 0.5$).

---

### Core Concepts & Formulations

#### Reciprocal Relationship

Recall the definition of the closed-loop Sensitivity Function: $$S(s) = \frac{1}{1 + L(s)} \implies |S(j\omega)| = \frac{1}{|1 + L(j\omega)|} \quad$$ Because $|1 + L(j\omega)|$ is the distance from $L(j\omega)$ to $-1$, the maximum sensitivity peak $M_s$ corresponds directly to the minimum Euclidean distance $s_m$: $$M_s = \max_{\omega} |S(j\omega)| = \frac{1}{\min_\omega |1 + L(j\omega)|} = \frac{1}{s_m} \iff s_m = \frac{1}{M_s} \quad$$

```
+-----------------------------------------------------------------------------------+
|                            The Sensitivity Duality                                |
|                                                                                   |
|     Large Distance to -1 (sm >> 0)  <=======>  Low Sensitivity Peak (Ms < 2)      |
|     - Nyquist curve stays clear of -1          - Moderate error amplification     |
|     - Robust against modeling errors           - Well-damped transient response   |
|                                                                                   |
|     Locus Approaches -1 (sm -> 0)   <=======>  Exploding Sensitivity Peak (Ms >>) |
|     - Operates near instability boundary       - Severe resonant amplification    |
|     - High oscillation and ringing             - Fragile closed-loop stability    |
+-----------------------------------------------------------------------------------+
```

_(Operational equivalence between geometric stability margin and sensitivity peaking)._

#### Constant Sensitivity Contours in the Nyquist Plane

A circle centered at $-1 + j0$ with radius $R_c$ represents a contour of constant sensitivity magnitude: $$|1 + L(j\omega)| = R_c \implies |S(j\omega)| = \frac{1}{R_c} \implies |S|_{\text{dB}} = -20\log_{10}(R_c) \quad$$

- **Disturbance Attenuation Zone ($R_c > 1$):** When $L(j\omega)$ lies outside the unit circle centered at $-1$ ($|1 + L| > 1$), $|S(j\omega)| < 1$ ($< 0\text{ dB}$), and feedback attenuates disturbances.
- **Disturbance Amplification Zone ($R_c < 1$):** When $L(j\omega)$ penetrates the unit circle centered at $-1$ ($|1 + L| < 1$), $|S(j\omega)| > 1$ ($> 0\text{ dB}$), and feedback amplifies disturbances.

## 6. Robust Stability Under Plant Uncertainty & The Small Gain Theorem

### Revision Checklist

- [ ] **Formulate the multiplicative uncertainty model** $P_{\text{actual}}(s) = P(s)(1 + \delta(s))$.
- [ ] **Derive the robust stability criterion** $|\delta(j\omega)| < \frac{1}{|T(j\omega)|}$ using Nyquist encirclement arguments.
- [ ] **State the Small Gain Theorem** for an interconnected feedback loop ($||H_1 \cdot H_2||_\infty < 1$).
- [ ] **Express the $H_\infty$ robust stability condition** $||T(s) W_m(s)||_\infty < 1$.
- [ ] **Explain how Complementary Sensitivity roll-off** ($T \to 0$ at high frequencies) accommodates large high-frequency modeling errors.

---

### Core Concepts & Formulations

#### Modeling Plant Uncertainty

A nominal plant model $P(s)$ inevitably deviates from the physical process $P_{\text{actual}}(s)$ due to unmodeled high-frequency structural resonances, parameter drift, and actuator lag. Uncertainty is commonly represented as:

1. **Additive Uncertainty:** $P_{\text{actual}}(s) = P(s) + \Delta(s)$.
2. **Multiplicative (Relative) Uncertainty:** $$P_{\text{actual}}(s) = P(s)\big(1 + \delta(s)\big) \quad \text{where} \quad \delta(s) = \frac{P_{\text{actual}}(s) - P(s)}{P(s)} \quad$$ where $\Delta(s)$ and $\delta(s)$ are assumed stable, and bounded by a known frequency-dependent weighting function: $|\delta(j\omega)| \le |W_m(j\omega)|$.

```
                +-------------------------------------------------------+
                | Multiplicative Uncertainty Block Diagram              |
                |                                                       |
                |                   +------------------+                |
                |          /------->|  δ(s) (Unknown)  |-------\        |
                |          |        +------------------+       |        |
                |          |                                   v        |
                |    r     |  +    u   +------+             +----+  y   |
                |   ----->(+)-----(+)--| P(s) |-------------| +  |----+ |
                |          ^ -     ^   +------+             +----+    | |
                |          |       |                           ^      | |
                |          |       \---------------------------/      | |
                |          |                                          | |
                |          +-----------------[ C(s) ]<----------------+ |
                +-------------------------------------------------------+
```

_(Feedback system with multiplicative plant uncertainty $\delta(s)$)._

#### Derivation of the Robust Stability Condition

When the nominal loop $L(s) = P(s)C(s)$ is perturbed by multiplicative uncertainty, the actual loop transfer function becomes: $$L_{\text{actual}}(s) = P_{\text{actual}}(s)C(s) = P(s)C(s)\big(1 + \delta(s)\big) = L(s) + L(s)\delta(s) \quad$$

In the complex plane, at each frequency $\omega$, the nominal point $L(j\omega)$ is surrounded by an uncertainty disk of radius $|L(j\omega)\delta(j\omega)|$. Assuming the nominal system is stable, the perturbed system remains stable if and only if the perturbed locus does not encircle or touch the critical point $-1$. Because the distance from $-1$ to the nominal point $L(j\omega)$ is $|1 + L(j\omega)|$, the uncertainty disk will not intersect $-1$ provided its radius is strictly smaller than this distance: $$|L(j\omega)\delta(j\omega)| < |1 + L(j\omega)|, \quad \forall \omega \ge 0 \quad$$

Dividing both sides by $|L(j\omega)|$ yields: $$|\delta(j\omega)| < \frac{|1 + L(j\omega)|}{|L(j\omega)|} = \frac{1}{|T(j\omega)|}, \quad \forall \omega \ge 0 \quad$$

#### The Small Gain Theorem Formulation

Isolating the uncertainty $\delta(s)$ into a standard feedback interconnection with the nominal system yields an effective transfer function looking back from the uncertainty ports of $-T(s) = -\frac{PC}{1 + PC}$. By the **Small Gain Theorem**, a closed-loop system comprising two stable interconnected operators is stable if the product of their gains is strictly less than unity: $$|\delta(s) \cdot T(s)|_\infty < 1 \iff |T(j\omega)| \cdot |W_m(j\omega)| < 1, \quad \forall \omega \quad$$

- **Design Implication:** At low frequencies, plant dynamics are well known ($|\delta| \ll 1$), allowing complementary sensitivity to remain near unity ($T \approx 1$) for accurate tracking. At high frequencies, where parasitic dynamics and phase shifts become large ($|\delta| \gg 1$), robust stability **demands that $T(j\omega)$ roll off rapidly to zero** ($|T(j\omega)| \ll 1/|\delta(j\omega)|$).

### Core Concepts & Formulations

#### The Concept of Conditional Stability

A system is **conditionally stable** if it is stable for a nominal gain, but becomes unstable if the gain is either increased _or_ decreased. This occurs when the Nyquist locus crosses the negative real axis multiple times.

- _Example:_ Consider the third-order loop transfer function: $$L(s) = \frac{3K(s + 6)^2}{s(s + 1)^2} \quad$$ Setting $K = 1$, the locus crosses the negative real axis twice:
    - First crossing: $L(j\omega) = -12$ at $\omega = 2\text{ rad/s}$.
    - Second crossing: $L(j\omega) = -4.5$ at $\omega = 3\text{ rad/s}$.

Because $L(s)$ has no open-loop RHP poles ($P = 0$), closed-loop stability requires zero net encirclements of $-1$ ($N = 0$).

- For $K > \frac{2}{9} \approx 0.222$, the critical point $-1$ lies to the right of the crossings, resulting in $N = 0$ (stable).
- If gain drops into the window $\frac{1}{12} < K < \frac{2}{9}$, the critical point falls between the loops, producing two clockwise encirclements ($N = 2 \implies Z = 2$, **unstable**).
- If gain is reduced further to $K < \frac{1}{12} \approx 0.083$, the plot shrinks entirely inside the critical point, restoring $N = 0$ (stable).
- **Operational Risk:** If an actuator experiences saturation or a power amplifier suffers a supply drop, the effective loop gain falls, potentially driving a conditionally stable system from a stable operating state directly into destructive oscillation.

## 8. Summary Comparison Table: Frequency-Domain Stability Metrics

| Robustness Metric                    | Mathematical Definition              | Domain / Location                                                | Strengths                                                                                    | Vulnerabilities / Limitations                                                        |
| :----------------------------------- | :----------------------------------- | :--------------------------------------------------------------- | :------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------- |
| **Gain Margin ($g_m$)** | $\dfrac{1}{\lvert L(j\omega_{pc})\rvert}$ | Nyquist real-axis crossing; Bode $-180^\circ$ phase line. | Simple factor by which loop gain can grow before instability. | Ignores phase; blind to near-misses between the axes. |
| **Phase Margin ($\phi_m$)**          | $180^\circ + \angle L(j\omega_{gc})$ | Nyquist unit circle crossing; Bode $0\text{ dB}$ magnitude line. | Directly correlates with damping ratio ($\zeta \approx \phi_m / 100$) and latency tolerance. | Evaluates only pure phase shift at $0\text{ dB}$; blind to mid-band resonant bulges. |
| **Stability Margin ($s_m$)** | $\min_\omega \lvert 1 + L(j\omega)\rvert$ | Shortest vector distance from Nyquist plot to $-1$. | Bounds simultaneous gain and phase perturbations; implies lower bounds on $g_m$ and $\phi_m$. | Needs the full frequency sweep; harder to read off a Bode plot by hand. |
| **Peak Sensitivity ($M_s$)** | $\max_\omega \lvert S(j\omega)\rvert = \dfrac{1}{s_m}$ | Peak magnitude of the sensitivity function $S(s)$. | Computed directly as $\lVert S\rVert_\infty$; one number summarizes robustness ($M_s < 2$). | Does not show where in the loop the weakness lies. |
| **Multiplicative Uncertainty Bound** | $\lvert T(j\omega)\rvert < \dfrac{1}{\lvert\delta(j\omega)\rvert}$ | Complementary sensitivity versus the relative-error bound. | Robust-stability guarantee against unmodeled dynamics. | Conservative; needs a frequency-dependent uncertainty weight. |

## 9. Practical MATLAB Implementation

```
%% ECE4132 Week 11: Nyquist Analysis and Robust Margins Script
clear; clc; close all;

% 1. Define Open-Loop Plant and Controller
s = tf('s');
% Example: 3rd-order plant with potential resonance
P = 3 / ((s + 1)^3);                 % Stable open-loop plant (P = 0)
C = 1.5 * (s + 2) / (s + 5);         % Lead-type compensator
L = P * C;

% 2. Open-Loop Pole Count
p_open = pole(L);
P_rhp  = sum(real(p_open) > 0);
fprintf('Open-Loop RHP Poles (P): %d\n', P_rhp);

% 3. Plot Nyquist Diagram
figure('Name', 'Nyquist Diagram with Stability Margin');
nyquist(L);
grid on; hold on;

% 4. Compute Classical Gain and Phase Margins
[Gm, Pm, Wcg, Wcp] = margin(L);
fprintf('Gain Margin (gm): %.2f (%.2f dB) at w_pc = %.2f rad/s\n', Gm, 20*log10(Gm), Wcp);
fprintf('Phase Margin (pm): %.2f deg at w_gc = %.2f rad/s\n', Pm, Wcg);

% 5. Compute Sensitivity, Stability Margin (sm), and Peak Sensitivity (Ms)
S = feedback(1, L);                 % S = 1 / (1 + L)
T = feedback(L, 1);                 % T = L / (1 + L)

Ms = norm(S, Inf);                  % Peak magnitude of S
sm = 1 / Ms;                        % Shortest distance to -1
fprintf('Peak Sensitivity (Ms): %.2f (%.2f dB)\n', Ms, 20*log10(Ms));
fprintf('Stability Margin (sm): %.2f\n', sm);

% 6. Draw Stability Margin Circle Centered at -1 on Nyquist Plot
theta = linspace(0, 2*pi, 300);
xc = -1 + sm * cos(theta);
yc = sm * sin(theta);
plot(xc, yc, 'r--', 'LineWidth', 1.5);
plot(-1, 0, 'r+', 'MarkerSize', 10, 'LineWidth', 2);
legend('L(s) locus', 'Stability Margin Circle (radius = s_m)', 'Critical Point (-1, 0)');
title(sprintf('Nyquist Plot: s_m = %.2f, M_s = %.2f', sm, Ms));

% 7. Robust Stability Check for Multiplicative Uncertainty
% Assume 20% low frequency error rising to 200% at high frequency
Wm = (2*s + 0.2) / (s + 1);         % Weighting filter bound
figure('Name', 'Robust Stability Verification');
bode(T, 'b', 1/Wm, 'r--');
grid on;
legend('|T(j\omega)|', '1 / |W_m(j\omega)| (Robustness Limit)');
title('Robust Stability: |T| must remain strictly below 1/|W_m|');
```
