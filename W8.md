### Core Concepts & Formulations

#### Formal Definition of Reachability

Consider the continuous-time linear state-space system: $$\dot{x}(t) = Ax(t) + Bu(t), \quad x(t) \in \mathbb{R}^n, ; u(t) \in \mathbb{R}^p$$

A continuous-time system is **reachable** if, for any initial state $x_0 \in \mathbb{R}^n$ and any target state $x_f \in \mathbb{R}^n$, there exists a finite time $T > 0$ and an admissible control signal $u(t)$ defined on $t \in [0, T]$ such that the state trajectory satisfies $x(0) = x_0$ and $x(T) = x_f$.

- **Reachability vs. Controllability:** Reachability refers to steering from an initial state to _any arbitrary_ final state $x_f$. Controllability strictly refers to steering any initial state to the _origin_ ($x_f = 0$) in finite time. For continuous-time linear time-invariant (LTI) systems, reachability and controllability are mathematically equivalent.
- **Equilibrium Subspace:** While transient trajectories can reach any point in $\mathbb{R}^n$ in a reachable system, steady states can only be sustained indefinitely at points where $\dot{x} = 0$, defined by the equilibrium subspace: $$\mathcal{R}_{\text{eq}} = {x_e \in \mathbb{R}^n \mid Ax_e + Bu_e = 0 \text{ for some } u_e \in \mathbb{R}^p}$$ If $A$ is invertible, this subspace is spanned by $A^{-1}B$.

#### Mechanisms of Unreachability

A system fails to be reachable when the control input cannot excite every natural mode or state coordinate independently:

1. **Actuator Symmetry / Redundant Dynamics:** When identical subsystems are driven by a single common actuator (for instance, two identical pendula of equal length and mass mounted on a single translational cart), the control force acts symmetrically on both subsystems. If both pendula begin at identical angles, no input force can steer them to differing angles because the dynamics do not "mix" the differential mode.
2. **Invariant Subspaces:** If there exists a non-zero row vector $H$ such that $\frac{d}{dt}(Hx(t)) = H(Ax(t) + Bu(t)) = 0$ for all states and inputs, then $H$ lies in the left null space of both $A$ and $B$ ($HA = 0$ and $HB = 0$). Consequently, $Hx(t)$ remains constant for all time, making it impossible for any input to steer the system from $x_0$ to $x_f$ whenever $Hx_0 \neq Hx_f$.

#### Popov-Belevitch-Hautus (PBH) Tests

- **PBH Reachability Test:** The pair $(A, B)$ is reachable if and only if: $$\text{rank}\begin{bmatrix} sI - A & B \end{bmatrix} = n, \quad \forall s \in \mathbb{C}$$ Equivalently, there exists no non-zero left eigenvector $v^T$ of $A$ ($v^T A = \lambda v^T$) that is orthogonal to $B$ ($v^T B = 0$).
- **Stabilizability:** A weaker condition than reachability. A system is **stabilizable** if all unreachable modes are naturally stable: $$\text{rank}\begin{bmatrix} sI - A & B \end{bmatrix} = n, \quad \forall s \in \mathbb{C} \text{ with } \text{Re}(s) \ge 0$$

## 2. The Reachability Matrix and Algebraic Proofs

### Core Concepts & Formulations

#### The Reachability Matrix

For a continuous-time system $(A, B)$ with $x \in \mathbb{R}^n$ and $u \in \mathbb{R}^p$, the **Reachability Matrix** $W_r$ is defined as: $$W_r = \begin{bmatrix} B & AB & A^2B & \dots & A^{n-1}B \end{bmatrix} \in \mathbb{R}^{n \times np}$$

#### Reachability Rank Condition

A continuous-time linear system is reachable if and only if its reachability matrix has full row rank: $$\text{rank}(W_r) = n$$ For single-input systems ($p = 1$), $W_r \in \mathbb{R}^{n \times n}$ is a square matrix, meaning the system is reachable if and only if $W_r$ is non-singular: $$\det(W_r) \neq 0$$

#### Mathematical Derivations

##### 1. Heuristic Derivation via Generalized Impulses

Starting from rest at $x(0) = 0$, apply a generalized impulse control input consisting of an impulse and its distributional derivatives: $$u(t) = \alpha_1 \delta(t) + \alpha_2 \dot{\delta}(t) + \alpha_3 \ddot{\delta}(t) + \dots + \alpha_n \delta^{(n-1)}(t)$$ Because the unforced impulse response kernel of $\dot{x} = Ax + Bu$ is $e^{At}B$, applying distributional differentiation properties yields: $$x(t) = \alpha_1 e^{At}B + \alpha_2 A e^{At}B + \alpha_3 A^2 e^{At}B + \dots + \alpha_n A^{n-1} e^{At}B$$ Evaluating the state trajectory immediately following the impulse burst ($t \to 0^+$) gives: $$\lim_{t \to 0^+} x(t) = \alpha_1 B + \alpha_2 AB + \alpha_3 A^2 B + \dots + \alpha_n A^{n-1} B = W_r \begin{bmatrix} \alpha_1 \ \alpha_2 \ \vdots \ \alpha_n \end{bmatrix}$$ To generate any arbitrary terminal vector $x(0^+) \in \mathbb{R}^n$, the linear operator $W_r$ must span the entire state space $\mathbb{R}^n$, which requires $\text{rank}(W_r) = n$.

##### 2. The Cayley-Hamilton Theorem and Dimensional Truncation

From the convolution integral for zero-state response: $$x(t) = \int_{0}^t e^{A(t - \tau)} B u(\tau) , d\tau = \int_{0}^t e^{A\tau} B u(t - \tau) , d\tau$$ By the **Cayley-Hamilton theorem**, every square matrix satisfies its own characteristic polynomial: $$\lambda_A(s) = \det(sI - A) = s^n + a_1 s^{n-1} + \dots + a_{n-1} s + a_n = 0 \implies A^n = -\sum_{i=1}^n a_i A^{n-i}$$ Consequently, every matrix power $A^k$ for $k \ge n$ can be rewritten as a linear combination of lower powers ${I, A, A^2, \dots, A^{n-1}}$. Therefore, the matrix exponential $e^{A\tau} = \sum_{k=0}^\infty \frac{\tau^k}{k!} A^k$ collapses to a finite expansion: $$e^{A\tau} = \sum_{k=0}^{n-1} \alpha_k(\tau) A^k$$ where $\alpha_k(\tau)$ are scalar functions of time. Substituting this into the state solution yields: $$x(t) = \sum_{k=0}^{n-1} A^k B \left[ \int_{0}^t \alpha_k(\tau) u(t - \tau) , d\tau \right] = W_r \begin{bmatrix} \int_{0}^t \alpha_0(\tau) u(t - \tau) , d\tau \ \vdots \ \int_{0}^t \alpha_{n-1}(\tau) u(t - \tau) , d\tau \end{bmatrix}$$ Because the reachable subspace is fundamentally the column space (image) of this mapping, considering powers higher than $n-1$ adds no linearly independent directions to the reachable set.

## 3. Reachable Canonical Form and Coordinate Transformations

### Revision Checklist

- [ ] **Write down the companion matrix structure** for the state dynamics matrix $\tilde{A}$ and input vector $\tilde{B}$ in Reachable Canonical Form.
- [ ] **State the relationship** between the first row of $\tilde{A}$ and the open-loop characteristic polynomial coefficients.
- [ ] **Derive the similarity transformation matrix** $T = \tilde{W}_r W_r^{-1}$ that converts an arbitrary reachable system into Reachable Canonical Form.
- [ ] **Demonstrate why the reachability matrix $\tilde{W}_r$ of the canonical form is upper-triangular** and always invertible.

---

### Core Concepts & Formulations

#### Canonical Structure

A single-input system is in **Reachable Canonical Form** (or Controller Canonical Form) if its state equations $\dot{z}(t) = \tilde{A}z(t) + \tilde{B}u(t)$ follow the companion structure: $$\tilde{A} = \begin{bmatrix} -a_1 & -a_2 & -a_3 & \dots & -a_{n-1} & -a_n \ 1 & 0 & 0 & \dots & 0 & 0 \ 0 & 1 & 0 & \dots & 0 & 0 \ \vdots & \vdots & \ddots & \dots & \vdots & \vdots \ 0 & 0 & \dots & 1 & 0 & 0 \ 0 & 0 & \dots & 0 & 1 & 0 \end{bmatrix}, \quad \tilde{B} = \begin{bmatrix} 1 \ 0 \ 0 \ \vdots \ 0 \ 0 \end{bmatrix}$$

The open-loop characteristic polynomial of $\tilde{A}$ directly matches the top row parameters: $$\det(sI - \tilde{A}) = s^n + a_1 s^{n-1} + a_2 s^{n-2} + \dots + a_{n-1}s + a_n$$

#### Canonical Reachability Matrix

The reachability matrix for a canonical realization, $\tilde{W}_r = \begin{bmatrix} \tilde{B} & \tilde{A}\tilde{B} & \dots & \tilde{A}^{n-1}\tilde{B} \end{bmatrix}$, possesses an upper triangular structure: $$\tilde{W}_r = \begin{bmatrix} 1 & -a_1 & a_1^2 - a_2 & \dots & * \ 0 & 1 & -a_1 & \dots & * \ 0 & 0 & 1 & \dots & * \ \vdots & \vdots & \vdots & \ddots & \vdots \ 0 & 0 & 0 & \dots & 1 \end{bmatrix}$$ Because all elements along the main diagonal are identically 1, $\det(\tilde{W}_r) = 1 \neq 0$ regardless of system dimension, confirming that **any system in reachable canonical form is inherently reachable**.

#### Derivation of the Coordinate Transformation Matrix $T$

To transform an arbitrary reachable system $\dot{x} = Ax + Bu$ into canonical form $\dot{z} = \tilde{A}z + \tilde{B}u$ via the linear change of coordinates $z = Tx$: $$\tilde{A} = TAT^{-1}, \quad \tilde{B} = TB$$

Evaluating the reachability matrix $\tilde{W}_r$ under this coordinate transformation: $$\tilde{A}^k \tilde{B} = (TAT^{-1})^k (TB) = T A^k B$$ $$\tilde{W}_r = \begin{bmatrix} \tilde{B} & \tilde{A}\tilde{B} & \dots & \tilde{A}^{n-1}\tilde{B} \end{bmatrix} = T \begin{bmatrix} B & AB & \dots & A^{n-1}B \end{bmatrix} = T W_r$$

Since $(A, B)$ is reachable, $W_r$ is invertible, providing the explicit transformation matrix: $$T = \tilde{W}_r W_r^{-1}$$

Furthermore, the inverse canonical reachability matrix $\tilde{W}_r^{-1}$ can be constructed directly as an upper-triangular Toeplitz matrix formed by the characteristic coefficients: $$\tilde{W}_r^{-1} = \begin{bmatrix} 1 & a_1 & a_2 & \dots & a_{n-1} \ 0 & 1 & a_1 & \dots & a_{n-2} \ 0 & 0 & 1 & \dots & a_{n-3} \ \vdots & \vdots & \vdots & \ddots & \vdots \ 0 & 0 & 0 & \dots & 1 \end{bmatrix}$$

### Core Concepts & Formulations

#### State Feedback Control Topology

Full-state feedback bypasses traditional scalar output compensation by feeding back every state variable through an adjustable gain vector:

```
                     v(t) (Input Disturbance)
                                |
                   +----+       v      +---------------+
   r(t) ---(kr)--->| +  |----->(+)---->| \dot{x}=Ax+Bu |----+---> y(t)
                   |    |       u(t)   | y = Cx + Du   |    |
                   | -  |<--\          +---------------+    |
                   +----+   |                  |            |
                            |                  | x(t)       |
                            +-------[ K ]<-----+            |
```

_(Block diagram representation of full-state feedback with reference precompensation and input disturbance)._

#### Closed-Loop Governing Equations

Assuming all states $x(t) \in \mathbb{R}^n$ can be measured directly, the control law is defined as: $$u(t) = -Kx(t) + k_r r(t) + v(t)$$ where $K = \begin{bmatrix} K_1 & K_2 & \dots & K_n \end{bmatrix} \in \mathbb{R}^{1 \times n}$ is the state feedback gain vector, and $k_r$ is the reference feedforward gain.

Substituting $u(t)$ into the open-loop dynamics yields: $$\dot{x}(t) = Ax(t) + B\left( -Kx(t) + k_r r(t) + v(t) \right) = (A - BK)x(t) + B k_r r(t) + B v(t)$$ $$y(t) = Cx(t) + D\left( -Kx(t) + k_r r(t) + v(t) \right) = (C - DK)x(t) + D k_r r(t) + D v(t)$$

#### Stability Criterion

The unforced stability and natural transient modes of the closed-loop system are governed entirely by the eigenvalues of the closed-loop system matrix $(A - BK)$: $$\det(sI - (A - BK)) = 0$$ The closed-loop system is internally stable if and only if all eigenvalues of $(A - BK)$ lie strictly in the open left-half complex plane: $$\text{Re}(\lambda_i(A - BK)) < 0, \quad \forall i \in {1, 2, \dots, n}$$

#### The Fundamental Theorem of Pole Placement

> **Theorem:** If the open-loop system pair $(A, B)$ is reachable, then for any arbitrary monic target polynomial of degree $n$ with real coefficients: $$\alpha_d(s) = s^n + t_1 s^{n-1} + t_2 s^{n-2} + \dots + t_{n-1}s + t_n$$ there exists a unique state feedback gain vector $K$ such that the closed-loop characteristic polynomial matches the target polynomial identically: $$\det(sI - (A - BK)) = \alpha_d(s)$$ This guarantees that all $n$ closed-loop eigenvalues can be placed at arbitrary pre-selected locations in the complex plane (with complex poles occurring in conjugate pairs).

### Core Concepts & Formulations

```
           Open-Loop Model (A, B) & Desired Roots {p1, p2, ..., pn}
                                     |
                         Check Reachability: rank(Wr) = n?
                                     |
                 +-------------------+-------------------+
                 |                                       |
    Method 1: Canonical Form                Method 2: Ackermann's Formula
                 |                                       |
    Form Companion Matrix A_tilde            Evaluate Matrix Polynomial:
    and Target Polynomial alpha_d(s)         alpha_d(A) = A^n + t1*A^(n-1) + ... + tn*I
                 |                                       |
    Solve: K_tilde_i = t_i - a_i             Compute: K = [0 ... 0 1] * inv(Wr) * alpha_d(A)
                 |                                       |

                 +-------------------+-------------------+
                                     |
                       Resulting State Feedback Law:
                           u(t) = -K*x(t) + kr*r(t)
```

### Method 1: Pole Placement via Reachable Canonical Form

1. **Find Open-Loop Polynomial:** Compute the characteristic polynomial of $A$: $$\det(sI - A) = s^n + a_1 s^{n-1} + \dots + a_{n-1}s + a_n$$
2. **Construct Target Polynomial:** From the desired closed-loop poles ${p_1, p_2, \dots, p_n}$, expand the target polynomial: $$\alpha_d(s) = \prod_{k=1}^n (s - p_k) = s^n + t_1 s^{n-1} + \dots + t_{n-1}s + t_n$$
3. **Calculate Gains in Canonical Coordinates:** In reachable canonical coordinates $z$, the control law $\tilde{u} = -\tilde{K}z$ modifies only the first row of $\tilde{A}$: $$\tilde{A} - \tilde{B}\tilde{K} = \begin{bmatrix} -(a_1 + \tilde{K}_1) & -(a_2 + \tilde{K}_2) & \dots & -(a_n + \tilde{K}_n) \ 1 & 0 & \dots & 0 \ \vdots & \ddots & \dots & \vdots \ 0 & \dots & 1 & 0 \end{bmatrix}$$ Matching coefficients directly with the target polynomial yields: $$\tilde{K}_i = t_i - a_i, \quad i = 1, 2, \dots, n$$
4. **Transform Back to Physical State Coordinates:** Since $z = Tx$, the feedback becomes $u = -\tilde{K}z = -\tilde{K}Tx = -Kx$: $$K = \tilde{K}T = \tilde{K} (\tilde{W}_r W_r^{-1})$$

---

### Method 2: Ackermann’s Formula

For single-input systems, Ackermann's formula bypasses the explicit construction of the similarity transformation matrix $T$: $$K = \begin{bmatrix} 0 & 0 & \dots & 0 & 1 \end{bmatrix} W_r^{-1} \alpha_d(A)$$ where $\alpha_d(A) \in \mathbb{R}^{n \times n}$ is the matrix evaluation of the desired polynomial: $$\alpha_d(A) = A^n + t_1 A^{n-1} + t_2 A^{n-2} + \dots + t_{n-1} A + t_n I$$

#### Analytical Derivation of Ackermann’s Formula (for $n = 3$)

Let $\tilde{A} = A - BK$ represent the closed-loop matrix. By the Cayley-Hamilton theorem, $\tilde{A}$ satisfies its target characteristic equation: $$\alpha_d(\tilde{A}) = \tilde{A}^3 + t_1 \tilde{A}^2 + t_2 \tilde{A} + t_3 I = 0$$

Examining successive matrix powers:

- $\tilde{A} = A - BK$
- $\tilde{A}^2 = (A - BK)^2 = A^2 - ABK - BK\tilde{A}$
- $\tilde{A}^3 = (A - BK)^3 = A^3 - A^2 BK - ABK\tilde{A} - BK\tilde{A}^2$

Substituting these powers into the polynomial expansion yields: $$\alpha_d(\tilde{A}) = \alpha_d(A) - \left[ A^2 BK + ABK\tilde{A} + BK\tilde{A}^2 + t_1(ABK + BK\tilde{A}) + t_2 BK \right] = 0$$ $$\alpha_d(A) = \begin{bmatrix} B & AB & A^2 B \end{bmatrix} \begin{bmatrix} t_2 K + t_1 K\tilde{A} + K\tilde{A}^2 \ t_1 K + K\tilde{A} \ K \end{bmatrix} = W_r \begin{bmatrix} * \ * \ K \end{bmatrix}$$

Premultiplying both sides by $W_r^{-1}$: $$W_r^{-1} \alpha_d(A) = \begin{bmatrix} * \ * \ K \end{bmatrix}$$ Premultiplying by the row selection vector $\begin{bmatrix} 0 & 0 & 1 \end{bmatrix}$ isolates the gain vector $K$: $$K = \begin{bmatrix} 0 & 0 & 1 \end{bmatrix} W_r^{-1} \alpha_d(A)$$

---

### Computational Pole Placement in MATLAB

- `K = acker(A, B, p)`: Direct implementation of Ackermann's formula. While versatile for single-input systems with repeated eigenvalues ($p_i = p_j$), it relies on inverting $W_r$ and evaluating high matrix powers $A^n$, making it numerically ill-conditioned for system orders $n > 10$ or weakly reachable plants.
- `K = place(A, B, p)`: Employs the numerically robust Kautsky-Nichols-Van Dooren algorithm. Applicable to multi-input systems, it optimizes eigenvector conditioning to maximize stability margins.
    - _Constraint:_ The multiplicity of any desired closed-loop pole cannot exceed the number of control inputs ($\text{multiplicity}(p_i) \le \text{rank}(B)$). For SISO plants, **all desired closed-loop poles must be strictly distinct**.

## 6. Reference Precompensation ($k_r$) & Integral Augmentation

### Revision Checklist

- [ ] **Derive the reference precompensation gain** $k_r$ to ensure unity steady-state closed-loop gain ($y_{ss} = r_{ss}$).
- [ ] **Explain why static feedforward gain $k_r$ fails to reject** constant input disturbances $v_0$ or survive plant parameter drift.
- [ ] **Formulate the state-space equations for an augmented system** incorporating an integral tracking error state $x_i$.
- [ ] **State the reachability condition** for the integral-augmented system matrix.

---

### Core Concepts & Formulations

#### Derivation of Precompensation Gain $k_r$

Full-state feedback regulates states toward zero. To track a non-zero reference setpoint $r(t)$, the reference signal is injected through a scaling gain $k_r$: $$\dot{x}(t) = (A - BK)x(t) + B k_r r(t), \quad y(t) = Cx(t) \quad (\text{assuming } D = 0)$$

At steady state under a constant step command $r(t) = r_{ss}$, state derivatives settle to zero ($\dot{x}_{ss} = 0$): $$0 = (A - BK)x_{ss} + B k_r r_{ss} \implies x_{ss} = -(A - BK)^{-1} B k_r r_{ss}$$ $$y_{ss} = C x_{ss} = -C (A - BK)^{-1} B k_r r_{ss}$$

To guarantee zero steady-state tracking error ($y_{ss} = r_{ss}$), the closed-loop DC gain must equal unity: $$\frac{y_{ss}}{r_{ss}} = 1 \implies k_r = -\frac{1}{C(A - BK)^{-1}B}$$ _Physical Meaning:_ The precompensation gain $k_r$ is precisely the reciprocal of the closed-loop system's zero-frequency (DC) transmission gain.

#### Vulnerability to Disturbances and Model Mismatch

If a constant input disturbance $v(t) = v_0$ acts on the plant input, the steady-state output becomes: $$y_{ss} = -C(A - BK)^{-1}B (k_r r_{ss} + v_0) = r_{ss} - C(A - BK)^{-1}B v_0$$ Because $k_r$ acts purely as an open-loop feedforward gain, it **cannot eliminate steady-state offsets caused by unmodeled plant parameter variations or constant load disturbances**.

#### Robust Tracking via Integral State Augmentation

To eliminate steady-state tracking error under constant disturbances without precise plant model calibration, introduce an integrator state $x_i(t)$ that continuously accumulates the tracking error $e_y(t) = r(t) - y(t)$: $$\dot{x}_i(t) = r(t) - y(t) = r(t) - Cx(t)$$

Constructing the augmented state vector $x_a(t) = \begin{bmatrix} x(t) \ x_i(t) \end{bmatrix} \in \mathbb{R}^{n+1}$ yields: $$\begin{bmatrix} \dot{x}(t) \ \dot{x}_i(t) \end{bmatrix} = \begin{bmatrix} A & 0 \ -C & 0 \end{bmatrix} \begin{bmatrix} x(t) \ x_i(t) \end{bmatrix} + \begin{bmatrix} B \ 0 \end{bmatrix} u(t) + \begin{bmatrix} 0 \ 1 \end{bmatrix} r(t)$$

The augmented state feedback control law becomes: $$u(t) = -Kx(t) - K_i x_i(t) = -\begin{bmatrix} K & K_i \end{bmatrix} \begin{bmatrix} x(t) \ x_i(t) \end{bmatrix}$$

The resulting augmented closed-loop system matrix is: $$A_a - B_a K_a = \begin{bmatrix} A - BK & -B K_i \ -C & 0 \end{bmatrix}$$

- **Reachability Condition for the Augmented System:** The augmented $(n+1)$-dimensional system is reachable if and only if the open-loop plant $(A, B)$ is reachable and the plant transfer function has no transmission zero at $s = 0$: $$\det \begin{bmatrix} A & B \ -C & 0 \end{bmatrix} \neq 0 \iff P(0) = -CA^{-1}B \neq 0$$ When this rank condition holds, the feedback gain vector $\begin{bmatrix} K & K_i \end{bmatrix}$ places all $n+1$ closed-loop eigenvalues in the open left-half plane, guaranteeing asymptotic disturbance rejection ($y_{ss} = r_{ss}$) even under plant parameter uncertainty.

---

### Core Concepts & Engineering Trade-offs

#### The Control Authority vs. Speed Dilemma

While the Pole Placement Theorem proves that eigenvalues can mathematically be shifted anywhere in the complex plane, physical hardware imposes strict operational boundaries:

|Performance Metric|Moving Closed-Loop Poles Farther Left ($\text{Re}(p_k) \ll 0$)|Moving Closed-Loop Poles Closer to the Imaginary Axis|
|:--|:--|:--|
|**Response Speed ($T_r, T_s$)**|**Significantly faster:** Rapid transient decay and short settling times.|**Slower:** Sluggish settling time, extended transient envelopes.|
|**Control Signal Magnitude ($|u(t)|$)**|
|**Actuator Saturation Risk**|**Severe:** Exceeds actuator voltage/torque/force limits, leading to windup or instability.|**Minimal:** System operates cleanly within its linear dynamic range.|
|**Sensor Noise Amplification**|**High:** High-gain feedback amplifies high-frequency measurement noise into the actuators.|**Low:** Natural low-pass filtering effect attenuates high-frequency sensor noise.|

#### Pole Selection via Second-Order Dominant Approximations

To balance performance against control effort, designers typically specify a pair of dominant complex-conjugate poles based on transient response requirements: $$p_{1,2} = -\zeta \omega_n \pm j \omega_n \sqrt{1 - \zeta^2}$$

- **Damping Ratio ($\zeta$):** Dictates percentage overshoot ($M_p$): $$M_p = \exp\left( -\frac{\pi \zeta}{\sqrt{1 - \zeta^2}} \right) \iff \zeta = \frac{-\ln(M_p)}{\sqrt{\pi^2 + \ln^2(M_p)}}$$
- **Natural Frequency ($\omega_n$):** Governs settling time ($T_s$) and rise time: $$T_s \approx \frac{4}{\zeta \omega_n} \quad (\text{for a } 2\% \text{ settling criterion})$$

#### Placement of Non-Dominant Poles

For an $n$-th order system ($n > 2$), the remaining $n - 2$ poles must not alter the transient performance governed by the dominant pair:

- **5x to 10x Rule:** Place non-dominant poles **5 to 10 times farther to the left** than the real part of the dominant complex poles ($|\text{Re}(p_{\text{non-dom}})| \ge 5 |\zeta \omega_n|$). This ensures their exponential modes decay rapidly, making them negligible in the transient response.
- **Zero Cancellation:** Alternatively, place non-dominant poles near open-loop plant zeros to minimize their residue and dynamic contribution to the step response.

|**Rank Condition**|$\text{rank}(W_r) = n \iff \det(W_r) \neq 0$|Necessary and sufficient condition for arbitrary eigenvalue assignment.|
|**Reachable Canonical Form**|$\tilde{A}_{\text{comp}}, ; \tilde{B} = \begin{bmatrix} 1 & 0 & \dots & 0 \end{bmatrix}^T$|Form where characteristic coefficients appear directly in the first row.|
|**State Feedback Control Law**|$u(t) = -Kx(t) + k_r r(t)$|Linear mapping from full state vector to control signal (note minus sign).|
|**Closed-Loop Dynamics**|$\dot{x} = (A - BK)x + B k_r r$|Modifies system modes to the eigenvalues of $(A - BK)$.|
|**Canonical Pole Placement**|$\tilde{K}_i = t_i - a_i, \quad K = \tilde{K}\tilde{W}_r W_r^{-1}$|Direct algebraic coefficient matching in canonical coordinates.|
|**Ackermann’s Formula**|$K = \begin{bmatrix} 0 & \dots & 1 \end{bmatrix} W_r^{-1} \alpha_d(A)$|Direct computational formula for single-input state feedback gain.|
|**Precompensation Gain**|$k_r = -[C(A - BK)^{-1}B]^{-1}$|Feedforward reference scaling enforcing unit closed-loop DC gain ($y_{ss} = r_{ss}$).|
|**Integral Augmentation**|$\dot{x}_i = r - y, ; u = -Kx - K_i x_i$|Adds internal error integration to reject constant input disturbances.|
