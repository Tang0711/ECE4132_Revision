## 1. Proportional (P) Control: Dynamics, Pole Motion, and Steady-State Offset

```
              r(t)        +   e(t)       +-------+  u(t)   +-------+        y(t)
              ----------->(x)----------->|  Kp   |-------->|  P(s) |----+---->
                           - ^           +-------+         +-------+    |
                             |                                          |
                             +------------------------------------------+
```

### 1.1 Mathematical Definition

Proportional control is the simplest feedback mechanism. The control command $u(t)$ is directly proportional to the instantaneous actuating error $e(t) = r(t) - y(t)$: $$u(t) = K_p e(t) = K_p [r(t) - y(t)] \quad \Longleftrightarrow \quad C(s) = K_p$$ The proportional gain $K_p$ acts as an adjustable amplifier that scales the corrective control effort applied to the plant.

### 1.2 Action on a Stable First-Order Plant

Consider a first-order plant with pole at $s = -a$: $$P(s) = \frac{1}{s + a}$$ Under unity negative feedback, the closed-loop transfer function from reference $r(t)$ to output $y(t)$ is: $$G_{ry}(s) = \frac{K_p P(s)}{1 + K_p P(s)} = \frac{K_p}{s + (a + K_p)}$$

- **Closed-Loop Pole Location**: The closed-loop pole is located at: $$s_{\text{cl}} = -(a + K_p)$$
- **Time Constant ($\tau$) and Speed**: The closed-loop time constant becomes: $$\tau_{\text{cl}} = \frac{1}{a + K_p}$$ Increasing $K_p > 0$ pushes the closed-loop pole farther to the left along the negative real axis. This accelerates the rate of exponential decay, reducing both the rise time ($T_r \approx 2.2\tau_{\text{cl}}$) and the $2%$ settling time ($T_s \approx 4\tau_{\text{cl}}$).
- **Stabilisation of Unstable Systems**: If the open-loop plant is unstable ($a < 0$, placing the pole in the right-half plane), choosing $K_p > |a|$ shifts the pole into the open left-half plane (OLHP), stabilizing the closed-loop system.

### 1.3 The Inevitability of Steady-State Offset in Type-0 Systems

Applying a unit step command ($R(s) = 1/s$) to this stable first-order closed-loop system yields the steady-state output via the Final Value Theorem: $$y(\infty) = \lim_{s \to 0} s Y(s) = \lim_{s \to 0} s \left( \frac{K_p}{s + a + K_p} \cdot \frac{1}{s} \right) = \frac{K_p}{a + K_p}$$ The resulting steady-state tracking error is: $$e(\infty) = r(\infty) - y(\infty) = 1 - \frac{K_p}{a + K_p} = \frac{a}{a + K_p}$$

```
   y(t) ^
        |
    1.0 | - - - - - - - - - - - - - - - - - - - - - Reference Setpoint r(t) = 1(t)
        |                                _ . - - - -
  y(∞)  |--------------------- _ . - ' '              ^
        |               _ . - '                       | Finite Steady-State
        |          _ - '                              | Offset: e(∞) = a / (a + Kp)
        |       .-'                                   v
        +------+------------------------------------------------------------> t
        0
```

- **Physical Meaning of Offset**: To hold the output at a nonzero constant value, the physical plant requires a continuous, non-zero driving input $u(\infty)$. Because $u(t) = K_p e(t)$, the error $e(t)$ cannot be zero; if it were, the control input would vanish ($u = 0$), causing the output to decay back to zero.
- **Limitation of High Gain**: Although increasing $K_p \to \infty$ reduces $e(\infty)$ towards zero, infinite gain is physically impossible. In higher-order plants ($n \ge 3$), excessive gain pushes root locus branches into the right-half plane, causing oscillations and instability.

## 2. Proportional-Derivative (PD) Control: Predictive Action & Dynamic Damping

To improve transient speed without causing the excessive oscillations associated with high proportional gains, derivative action is introduced.

```
                            +---------------+
                            |     Kd s      | (Derivative Path)
                     +----->| (Anticipator) |------+
                     |      +---------------+      |
     e(t)            |                             v   +
   --------->(x)-----+                             (x)---> u(t)
              |      |      +---------------+      ^   +
              |      +----->|      Kp       |------+
              |             | (Proportional)|
              |             +---------------+
              v
     Error Velocity de/dt
```

### 2.1 The Ideal PD Control Law

The ideal Proportional-Derivative controller produces a control signal driven by both error magnitude and error velocity: $$u(t) = K_p e(t) + K_d \frac{de(t)}{dt} \quad \Longleftrightarrow \quad C(s) = K_p + K_d s = K_d \left( s + \frac{K_p}{K_d} \right)$$

- **$K_p$ (Proportional Gain)**: Provides restoring action proportional to the instantaneous displacement from the reference.
- **$K_d$ (Derivative Gain)**: Provides viscous damping action proportional to the speed at which the error is changing.
- **Open-Loop Zero**: A PD controller introduces an open-loop zero into the forward path at: $$s = -z_c = -\frac{K_p}{K_d}$$

### 2.2 Physical Intuition: Predictive and Anticipatory Action

Consider a system approaching its target setpoint rapidly:

1. While the instantaneous error $e(t) > 0$ remains positive, the error derivative $\dot{e}(t) < 0$ is negative because the error is shrinking.
2. The derivative term $K_d \dot{e}(t)$ subtracts from the proportional command $K_p e(t)$, applying an early braking action before the output overshoots the setpoint.
3. Conversely, if an external disturbance suddenly deflects the plant away from equilibrium, $\dot{e}(t)$ surges immediately, injecting immediate control effort before a large error accumulates.

### 2.3 Second-Order Pole Placement via PD Control

Consider a general uncompensated second-order plant: $$P(s) = \frac{K}{s^2 + a_1 s + a_0}$$ Placing this plant in a unity feedback loop with a PD controller $C(s) = K_p + K_d s$ yields the loop transfer function: $$L(s) = P(s)C(s) = \frac{K(K_d s + K_p)}{s^2 + a_1 s + a_0}$$

The closed-loop characteristic equation is: $$1 + L(s) = 0 \implies s^2 + a_1 s + a_0 + K(K_d s + K_p) = 0$$ $$\Delta(s) = s^2 + (a_1 + K K_d) s + (a_0 + K K_p) = 0$$

Comparing this with the prototype second-order polynomial $s^2 + 2\zeta\omega_n s + \omega_n^2$ reveals how the parameters are tuned: $$\omega_n = \sqrt{a_0 + K K_p}, \qquad 2\zeta\omega_n = a_1 + K K_d \implies \zeta = \frac{a_1 + K K_d}{2\sqrt{a_0 + K K_p}}$$

```
   Parameter Roles:
   - Proportional Gain Kp  ---> Adjusts constant term (Stiffness / Natural Frequency ωn)
   - Derivative Gain Kd    ---> Adjusts linear coefficient (Damping / Damping Ratio ζ)
```

Because $K_p$ and $K_d$ enter separate coefficients, a designer can place the two closed-loop poles at any desired locations in the complex plane. This enables simultaneous tuning of response speed ($\omega_n$) and relative stability ($\zeta$), which is impossible with pure proportional gain.

## 3. Reshaping the Root Locus via Derivative Compensation

When a system's open-loop root locus does not pass through the desired closed-loop pole locations, gain adjustment alone cannot meet the design specifications. Adding a compensator zero pulls the locus toward the left-half plane.

```
                     Uncompensated vs. PD-Compensated Root Locus
                                      jω
                                       |
                     Desired Pole s0   |
                            x          |            x Open-Loop Pole
                           /           |
                          /            |
                         /             |
         -zc            /              |
   -------o------------*---------------x--------------------------> σ
      PD Zero      Breakaway       Open-Loop
                                     Poles
```

### 3.1 The Angle Deficiency Formulation

Let $s_0 = -\zeta\omega_n + j\omega_d$ represent the desired closed-loop dominant pole calculated from transient specifications ($T_s, M_p, T_p$). For $s_0$ to lie on the compensated root locus, the loop transfer function must satisfy the Evans Angle Condition: $$\angle L(s_0) = \sum_{j=1}^{m} \angle(s_0 - z_j) - \sum_{i=1}^{n} \angle(s_0 - p_i) = \pm 180^\circ(2k + 1)$$

If evaluating the uncompensated plant poles and zeros at $s_0$ yields an angle sum $\theta_{\text{uncomp}} \ne \pm 180^\circ$, the difference is the **angle deficiency** $\phi_{\text{def}}$: $$\phi_{\text{def}} = 180^\circ - \sum_{j=1}^{m} \angle(s_0 - z_j) + \sum_{i=1}^{n} \angle(s_0 - p_i)$$ The compensator must contribute this angle $\phi_c = \phi_{\text{def}}$ at $s_0$ to pull the locus through the design point.

### 3.2 Calculating the Compensator Zero Location

For an ideal PD controller $C(s) = K_d(s + z_c)$, the angle contributed by the single zero at $s = -z_c$ is: $$\angle(s_0 + z_c) = \theta_z = \phi_{\text{def}}$$

Using the geometry of the complex plane:

```
                              jω
                               |          s0 = -σ0 + jωd
                               |           *
                               |          /|
                               |         / |
                               |        /  | ωd
                               |       /   |
                               |  θz  /    |
   ----------------------------+-----o-----+-----------------------> σ
                             -zc    -σ0    0
                               <----->
                               zc - σ0
```

From trigonometry: $$\tan(\theta_z) = \frac{\omega_d}{z_c - \sigma_0} \implies z_c = \sigma_0 + \frac{\omega_d}{\tan(\theta_z)}$$ where $\sigma_0 = \zeta\omega_n$ and $\omega_d = \omega_n\sqrt{1 - \zeta^2}$. Once the zero is placed, the loop gain $K$ is calculated using the Evans Magnitude Condition: $$K = \frac{1}{|P(s_0)C(s_0)|} = \frac{\prod_{i=1}^{n} |s_0 - p_i|}{|s_0 + z_c| \prod_{j=1}^{m} |s_0 - z_j|}$$

## 4. Practical Implementation: Derivative Filtering & Lead Compensation

### 4.1 The High-Frequency Noise Problem

Although ideal PD control ($C(s) = K_p + K_d s$) is mathematically convenient, it **cannot be implemented with passive physical hardware** because its transfer function is improper ($m > n$). In the frequency domain ($s = j\omega$): $$|C(j\omega)| = |K_p + j\omega K_d| = \sqrt{K_p^2 + \omega^2 K_d^2} \xrightarrow{\omega \to \infty} \infty$$

```
   Gain |C(jω)| ^
                |                      / Pure Ideal Derivative (Unbounded Gain)
                |                     /
                |                    /
                |                   +---------------- Practical Filtered Derivative
                |                  /                  (Gain capped at high frequency)
            Kp -+-----------------+
                |
                +------------------------------------------------------------> Frequency ω
```

- **Amplification of Sensor Noise**: Measurement signals from physical sensors (encoders, tachometers, IMUs) contain high-frequency electronic noise and quantization jitter. Pure differentiation amplifies this high-frequency noise, causing severe actuator chatter, mechanical wear, and driving the amplifier into continuous saturation.

### 4.2 Practical Filtered Derivative

To resolve this issue, practical controllers add a first-order low-pass filter pole to the derivative term: $$C_{\text{filtered}}(s) = K_p + K_d \frac{s}{\frac{s}{N} + 1} = K_p + \frac{K_d N s}{s + N}$$ where $N$ is the derivative filter coefficient (typically $8 \le N \le 20$).

- At low frequencies ($\omega \ll N$), the controller behaves like an ideal differentiator: $\frac{s}{s/N + 1} \approx s$.
- At high frequencies ($\omega \gg N$), the gain rolls off and is capped at $K_p + K_d N$, preventing noise amplification.

### 4.3 Lead Compensator Equivalence

Rearranging the filtered PD controller into a rational transfer function reveals its structural equivalence to a **phase-lead compensator**: $$C(s) = \frac{(K_p + K_d N)s + K_p N}{s + N} = K_c \frac{s + z_c}{s + p_c}$$ where: $$z_c = \frac{K_p N}{K_p + K_d N}, \qquad p_c = N, \qquad K_c = K_p + K_d N$$

```
                          Lead Compensator Pole-Zero Map
                                       jω
                                        |
                 Pole pc                |    Zero zc
   -----------------x-------------------+-------o-------------------> σ
                  -N                    |      -zc                  0
                    <-------------------|
                        pc > zc (Phase Lead)
```

A **Lead Compensator** places its pole farther to the left on the real axis than its zero ($p_c > z_c$).

- **Phase Contribution**: Because the zero is closer to the imaginary axis than the pole, its positive phase angle dominates over the pole's negative phase angle, providing a net positive phase lead ($\angle C(j\omega) > 0$) across intermediate frequencies.
- **High-Frequency Attenuation**: Unlike pure differentiation, high-frequency gain is strictly bounded by $K_c \frac{p_c}{z_c}$, protecting the physical hardware from sensor noise.

## 5. Design Trade-Offs and Actuator Constraints

Engineering design requires balancing multiple competing performance specifications:

|Performance Dimension|Proportional (P) Control|Proportional-Derivative (PD) / Lead Control|
|:--|:--|:--|
|**Response Speed ($T_r, T_s$)**|High gain reduces rise time and settling time on first-order plants.|Significantly reduces $T_r$ and $T_s$ by shifting dominant poles farther into the OLHP.|
|**Damping & Overshoot ($M_p$)**|High gain degrades relative stability in second- and higher-order plants, increasing overshoot.|The derivative term adds dynamic damping, suppressing overshoot and oscillations.|
|**Steady-State Tracking**|Leaves a finite offset error $e_{ss} = \frac{a}{a+K_p}$ on Type-0 plants.|**Does not eliminate steady-state error**; requires an integrator (PI/PID) to achieve $e_{ss} = 0$.|
|**Sensor Noise Sensitivity**|Low sensitivity; proportional gain scales error uniformly across frequencies.|High sensitivity; unmitigated derivative action amplifies high-frequency noise.|
|**Actuator Control Effort**|Control effort scales directly with error amplitude: $u(0^+) = K_p \Delta r$.|Produces sharp control effort spikes on step setpoints ($\dot{r} \to \infty$), risking actuator saturation.|

## 6. Worked Design Example: PD Controller via Root Locus

Consider a positioning system with open-loop plant: $$P(s) = \frac{10}{s(s + 2)}$$ **Design Objective**: Design a controller such that the closed-loop dominant poles have a damping ratio $\zeta = 0.5$ and a settling time $T_s \le 1.0\text{ s}$ ($2%$ criterion).

### Step 1: Determine the Desired Closed-Loop Pole Locations

From the settling time specification: $$\sigma_0 = \zeta\omega_n = \frac{4}{T_s} = \frac{4}{1.0} = 4.0\text{ rad/s}$$ From the damping ratio $\zeta = 0.5$: $$\omega_n = \frac{\sigma_0}{\zeta} = \frac{4.0}{0.5} = 8.0\text{ rad/s}$$ The damped natural frequency is: $$\omega_d = \omega_n \sqrt{1 - \zeta^2} = 8.0 \sqrt{1 - 0.25} = 8.0 \frac{\sqrt{3}}{2} \approx 6.928\text{ rad/s}$$ Thus, the desired dominant closed-loop pole is: $$s_0 = -4.0 + j6.928$$

### Step 2: Evaluate the Uncompensated System at $s_0$

Check whether $s_0$ lies on the uncompensated root locus of $P(s) = \frac{10}{s(s + 2)}$:

- Angle from pole at $s = 0$: $$\theta_{p1} = 180^\circ - \arctan\left(\frac{6.928}{4.0}\right) = 180^\circ - 60.0^\circ = 120.0^\circ$$
- Angle from pole at $s = -2$: $$\theta_{p2} = 180^\circ - \arctan\left(\frac{6.928}{4.0 - 2.0}\right) = 180^\circ - \arctan(3.464) = 180^\circ - 73.9^\circ = 106.1^\circ$$
- Sum of uncompensated pole angles: $$\sum \theta_p = 120.0^\circ + 106.1^\circ = 226.1^\circ$$

The angle condition requires $180^\circ$. The **angle deficiency** is: $$\phi_{\text{def}} = 226.1^\circ - 180^\circ = 46.1^\circ$$ Because $\phi_{\text{def}} > 0$, the uncompensated root locus passes to the right of $s_0$, and gain adjustment alone cannot meet the specifications. A PD controller zero must contribute $\theta_z = 46.1^\circ$.

### Step 3: Calculate the PD Zero Location ($z_c$)

From the geometry of the compensator zero: $$\tan(46.1^\circ) = \frac{\omega_d}{z_c - \sigma_0} = \frac{6.928}{z_c - 4.0}$$ $$z_c - 4.0 = \frac{6.928}{\tan(46.1^\circ)} = \frac{6.928}{1.039} \approx 6.668 \implies z_c \approx 10.67$$ The PD controller structure is: $$C(s) = K_d(s + 10.67)$$

### Step 4: Calculate the Loop Gain via the Magnitude Condition

Evaluate the magnitude condition at $s_0 = -4.0 + j6.928$: $$|s_0| = \sqrt{4^2 + 6.928^2} = 8.0$$ $$|s_0 + 2| = \sqrt{(4 - 2)^2 + 6.928^2} = \sqrt{4 + 48} = \sqrt{52} \approx 7.211$$ $$|s_0 + z_c| = |s_0 + 10.67| = \sqrt{(10.67 - 4)^2 + 6.928^2} = \sqrt{6.67^2 + 48} = \sqrt{44.49 + 48} \approx 9.617$$

The loop gain requires: $$1 = |C(s_0) P(s_0)| = \frac{10 K_d |s_0 + z_c|}{|s_0| |s_0 + 2|}$$ $$K_d = \frac{|s_0| |s_0 + 2|}{10 |s_0 + z_c|} = \frac{8.0 \times 7.211}{10 \times 9.617} = \frac{57.69}{96.17} \approx 0.60$$

### Step 5: Extract Controller Gains

$$K_d = 0.60$$ $$K_p = K_d \cdot z_c = 0.60 \times 10.67 \approx 6.40$$ The final PD controller is: $$C(s) = 6.40 + 0.60 s$$

## 7. Comprehensive Review Matrix

|Component / Parameter|Transfer Function / Governing Formula|Primary Influence on Loop Performance|
|:--|:--|:--|
|**Proportional Gain ($K_p$)**|$C(s) = K_p$|Increases response speed and reduces steady-state offset; excessive values induce oscillations.|
|**Derivative Gain ($K_d$)**|$C(s) = K_d s$|Injects phase lead and active damping; reduces overshoot and settling time.|
|**Compensator Zero ($z_c$)**|$s = -z_c = -K_p / K_d$|Pulls root locus branches leftward into the stable region of the $s$-plane.|
|**Angle Deficiency ($\phi_{\text{def}}$)**|$\phi_{\text{def}} = 180^\circ - \sum \theta_z + \sum \theta_p$|Determines the exact phase lead required from the compensator at design point $s_0$.|
|**Derivative Filter ($N$)**|$\frac{s}{\frac{s}{N} + 1}$ ($8 \le N \le 20$)|Caps high-frequency controller gain at $K_p + K_d N$, preventing sensor noise amplification.|
|**Lead Compensator**|$K_c \frac{s + z_c}{s + p_c}$ with $p_c > z_c$|Physical, proper realization of PD action; bounds high-frequency gain while providing phase lead.|
