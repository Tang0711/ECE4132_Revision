### Core Concepts & Formulations

#### Limitations of Direct Full-State Feedback

Full-state feedback ($u(t) = -Kx(t) + k_r r(t)$) assumes all $n$ internal state variables are directly accessible via sensors. In practical engineering implementations:

- Physical sensors for every state may be prohibitively expensive, add unacceptable weight, or reduce system reliability.
- Certain internal dynamic states cannot be physically accessed or measured directly by any sensor.
- Sensor measurements introduce high-frequency electrical noise that corrupts state derivatives.

To resolve this, an **output feedback architecture** is employed: an auxiliary dynamic system called a **state estimator (observer)** reconstructs an estimate of the state vector $\hat{x}(t) \in \mathbb{R}^n$ using only the applied input $u(t)$ and the measured output $y(t)$.

```
                 +-------------------------------------------------------+
                 | Dynamic Output Feedback Controller                    |
                 |                                                       |
                 |    +---------------------------------------------+    |
                 |    | \dot{\hat{x}}(t) = E \hat{x}(t) + F [r; y]  |    |
                 |    |                                             |    |
                 |    |       u(t) = G \hat{x}(t) + H [r; y]        |    |
                 |    +---------------------------------------------+    |
                 +-----------------------|-------------------------------+
                                         | u(t)
                                         v
                                  +---------------+
                                  | \dot{x}=Ax+Bu |
                                  | y = Cx        |-----> y(t)
                                  +---------------+
                                       Plant
```

_(General structure of a dynamic output feedback controller)._

#### The Open-Loop Estimator ("Copying the Plant")

The simplest state estimator is an open-loop software simulator that mirrors the nominal plant dynamics driven by the known input $u(t)$: $$\dot{\hat{x}}(t) = A\hat{x}(t) + Bu(t), \quad \hat{x}(0) = \hat{x}_0$$

Defining the state estimation error as $\tilde{x}(t) = x(t) - \hat{x}(t)$: $$\dot{\tilde{x}}(t) = \dot{x}(t) - \dot{\hat{x}}(t) = (Ax(t) + Bu(t)) - (A\hat{x}(t) + Bu(t)) = A\tilde{x}(t)$$ $$\tilde{x}(t) = e^{At}\tilde{x}(0)$$

**Why Open-Loop Estimation Fails:**

1. **Unstable Plants:** If the open-loop matrix $A$ has any eigenvalue with $\text{Re}(\lambda) \ge 0$, any initial discrepancy $\tilde{x}(0) \neq 0$ grows exponentially without bound, causing the state estimate to diverge.
2. **Lack of Tuning Freedom:** Even if the plant is stable ($\text{Re}(\lambda_i) < 0$), the estimation error decays only as fast as the plant's open-loop natural modes. If an eigenvalue lies close to the imaginary axis, convergence is excessively slow.
3. **Absence of Feedback Correction:** The open-loop estimator completely ignores the measured output $y(t)$, preventing the observer from correcting for disturbances or modeling errors.

### Core Concepts & Formulations

#### Formal Definition of Observability

Consider the linear time-invariant system: $$\dot{x}(t) = Ax(t) + Bu(t), \quad y(t) = Cx(t)$$

A continuous-time system is **observable** if, for any initial state $x(0) \in \mathbb{R}^n$ and any finite time $T > 0$, the initial state $x(0)$ can be uniquely determined from knowledge of the input trajectory $u(t)$ and the output trajectory $y(t)$ measured over the interval $t \in [0, T]$.

- If $x(0)$ can be determined, then the current state $x(t)$ can be reconstructed for all $t \ge 0$ by integrating the known dynamics.
- Because the input $u(t)$ and the input matrices $(A, B)$ are known, the zero-state contribution $\int_0^t C e^{A(t-\tau)} B u(\tau) d\tau$ can be subtracted from $y(t)$. Therefore, observability depends strictly on the autonomous pair $(A, C)$.

#### Mechanisms of Unobservability

A system is unobservable when certain internal states or natural modes fail to transmit any dynamical signature to the measured output sensors:

- **Symmetric Opposing Dynamics:** If two identical subsystems $S$ with identical initial conditions feed into a summing junction where their outputs subtract ($y = y_1 - y_2$), the net output remains identically zero ($y(t) \equiv 0$) for all time regardless of the magnitude of their shared motion.
- **Decoupled States:** If a state coordinate has zero coupling to the output row ($C_i = 0$) and the system dynamics matrix $A$ does not mix that state into observable states, that coordinate cannot be detected from $y(t)$.

#### Derivation of the Observability Matrix

For an unforced system ($\dot{x} = Ax, ; y = Cx$), the output trajectory is $y(t) = C e^{At} x(0)$. Taking successive time derivatives at $t = 0$: $$y(0) = C x(0)$$ $$\dot{y}(0) = C \dot{x}(0) = CA x(0)$$ $$\ddot{y}(0) = CA \dot{x}(0) = CA^2 x(0)$$ $$\vdots$$ $$y^{(n-1)}(0) = CA^{n-1} x(0)$$

Stacking these scalar equations into matrix form yields: $$\begin{bmatrix} y(0) \ \dot{y}(0) \ \vdots \ y^{(n-1)}(0) \end{bmatrix} = \begin{bmatrix} C \ CA \ \vdots \ CA^{n-1} \end{bmatrix} x(0) = W_o x(0)$$

By the **Cayley-Hamilton theorem**, $A^n$ and all higher matrix powers can be expressed as linear combinations of ${I, A, A^2, \dots, A^{n-1}}$. Thus, taking derivatives higher than $n - 1$ produces rows that are linearly dependent on preceding rows, yielding no additional information about $x(0)$.

#### The Observability Matrix and Rank Condition

The **Observability Matrix** $W_o$ (or $\mathcal{O}$) is defined as: $$W_o = \begin{bmatrix} C \ CA \ CA^2 \ \vdots \ CA^{n-1} \end{bmatrix} \in \mathbb{R}^{nq \times n}$$

- **Observability Rank Condition:** The pair $(A, C)$ is observable if and only if $W_o$ has full column rank: $$\text{rank}(W_o) = n$$
- For a **single-output system** ($q = 1$), $W_o \in \mathbb{R}^{n \times n}$ is square, and the criterion simplifies to: $$\det(W_o) \neq 0$$

#### The Unobservable Subspace

If $\text{rank}(W_o) < n$, the nullspace of $W_o$ defines the **unobservable subspace**: $$\mathcal{N}(W_o) = \ker(W_o) = { x_0 \in \mathbb{R}^n \mid W_o x_0 = 0 }$$ For any initial state $x(0) \in \ker(W_o)$, the output trajectory is identically zero ($y(t) = C e^{At} x(0) \equiv 0$) for all $t \ge 0$. The sensors are completely blind to any dynamic mode residing within this subspace.

### Core Concepts & Formulations

#### The Principle of Duality

There exists a direct mathematical equivalence between the state controllability of a system and the observability of a dual transposed system: $$\text{Pair } (A, B) \text{ is reachable} \iff \text{Pair } (A^T, B^T) \text{ is observable}$$ $$\text{Pair } (A, C) \text{ is observable} \iff \text{Pair } (A^T, C^T) \text{ is reachable}$$

#### Algebraic Proof of Duality

Evaluating the observability matrix of the dual pair $(A^T, B^T)$: $$W_o(A^T, B^T) = \begin{bmatrix} B^T \ B^T A^T \ \vdots \ B^T (A^T)^{n-1} \end{bmatrix} = \begin{bmatrix} B^T \ (AB)^T \ \vdots \ (A^{n-1}B)^T \end{bmatrix} = \begin{bmatrix} B & AB & \dots & A^{n-1}B \end{bmatrix}^T = W_r(A, B)^T$$

Because the rank of a matrix equals the rank of its transpose ($\text{rank}(W_o) = \text{rank}(W_r^T) = \text{rank}(W_r)$) and $\det(W_o) = \det(W_r^T) = \det(W_r)$, the pair $(A, B)$ is reachable if and only if $(A^T, B^T)$ is observable.

#### Mathematical Duality Mapping

Because of duality, any theorem, algorithm, or software function developed for state feedback controller design applies directly to state observer design:

|Reachability / Controller Design ($u = -Kx$)|Observability / Observer Design ($\dot{\hat{x}} = (A-LC)\hat{x} + \dots$)|
|:--|:--|
|Dynamics Matrix: $A$|Dynamics Matrix: $A^T$|
|Input Matrix: $B$|Output Matrix: $C^T$|
|Reachability Matrix: $W_r = [B ; AB ; \dots ; A^{n-1}B]$|Transposed Observability Matrix: $W_o^T = [C^T ; A^TC^T ; \dots ; (A^T)^{n-1}C^T]$|
|Controller Feedback Gain: $K$|Transposed Observer Gain: $L^T$|
|Closed-Loop Matrix: $(A - BK)$|Error Dynamics Matrix Transpose: $(A - LC)^T = (A^T - C^T L^T)$|
|Characteristic Equation: $\det(sI - (A - BK)) = 0$|Characteristic Equation: $\det(sI - (A - LC)) = 0$|

#### Observable Canonical Form

A single-output system with open-loop characteristic polynomial $\det(sI - A) = s^n + a_1 s^{n-1} + \dots + a_n$ is in **Observable Canonical Form** if its matrices take the structure: $$A_{\text{obs}} = \begin{bmatrix} -a_1 & 1 & 0 & \dots & 0 \ -a_2 & 0 & 1 & \dots & 0 \ \vdots & \vdots & \vdots & \ddots & \vdots \ -a_{n-1} & 0 & 0 & \dots & 1 \ -a_n & 0 & 0 & \dots & 0 \end{bmatrix}, \quad C_{\text{obs}} = \begin{bmatrix} 1 & 0 & 0 & \dots & 0 \end{bmatrix}$$

- **Dual Relation:** Comparing with Reachable Canonical Form shows that $A_{\text{obs}} = A_{\text{reach}}^T$ and $C_{\text{obs}} = B_{\text{reach}}^T$.
- Any system in observable canonical form has an upper-triangular observability matrix with ones on the main diagonal, guaranteeing that it is **inherently observable**.

## 4. Full-Order Luenberger State Observers

### Revision Checklist

- [ ] **Show that the error dynamics are unforced** and completely decoupled from control inputs $u(t)$ and references $r(t)$.
- [ ] **State the condition for asymptotic estimation error convergence** ($\text{Re}(\lambda_i(A - LC)) < 0$).

### Core Concepts & Formulations

#### The Luenberger Observer Structure

To ensure rapid, stable state reconstruction even for unstable plants, David Luenberger introduced a closed-loop estimator that runs a real-time software model of the plant corrected by an **innovation term** proportional to the output estimation mismatch:

$$\dot{\hat{x}}(t) = A\hat{x}(t) + Bu(t) + L \left( y(t) - C\hat{x}(t) \right)$$ $$\hat{y}(t) = C\hat{x}(t)$$

Grouping internal feedback terms highlights the closed-loop nature of the estimator: $$\dot{\hat{x}}(t) = (A - LC)\hat{x}(t) + Bu(t) + Ly(t)$$ where $L \in \mathbb{R}^{n \times q}$ is the **Observer Gain Matrix**.

```
                     u(t)
                      |
                      v
             +-----------------+
    y(t) --->|  +              |
             |  |   \dot{\hat{x}} = (A-LC)\hat{x} + Bu + Ly   |-----> \hat{x}(t)
             |  L              |
             +-----------------+
```

_(The observer viewed as a dynamic system with inputs $u(t)$ and $y(t)$, and output $\hat{x}(t)$)._

#### Derivation of the Estimation Error Dynamics

Define the state estimation error as: $$e(t) = \tilde{x}(t) = x(t) - \hat{x}(t)$$

Differentiating with respect to time and substituting the plant and observer equations: $$\dot{e}(t) = \dot{x}(t) - \dot{\hat{x}}(t)$$ $$\dot{e}(t) = \left( Ax(t) + Bu(t) \right) - \left[ A\hat{x}(t) + Bu(t) + L(Cx(t) - C\hat{x}(t)) \right]$$ $$\dot{e}(t) = A(x(t) - \hat{x}(t)) - LC(x(t) - \hat{x}(t))$$ $$\dot{e}(t) = (A - LC)e(t)$$

The explicit time-domain solution for the error vector is: $$e(t) = \exp\left( (A - LC)t \right) e(0)$$

#### Key Analytical Properties of the Error Dynamics

1. **Decoupled from Plant Driving Signals:** The control input $u(t)$ and reference $r(t)$ cancel out completely. The error dynamics are strictly autonomous.
2. **Asymptotic Convergence:** If the gain matrix $L$ is designed such that all eigenvalues of the error dynamics matrix $(A - LC)$ lie strictly in the open left-half complex plane: $$\text{Re}(\lambda_i(A - LC)) < 0, \quad \forall i \in {1, 2, \dots, n}$$ then the estimation error decays asymptotically to zero ($\lim_{t \to \infty} e(t) = 0$) regardless of the initial mismatch $\hat{x}(0) \neq x(0)$.
3. **Eigenvalue Assignment Freedom:** If $(A, C)$ is observable, the eigenvalues of $(A - LC)$ can be placed at arbitrary locations in the complex plane (with complex poles in conjugate pairs).

## 5. Systematic Observer Gain Synthesis

### Revision Checklist

### Core Concepts & Formulations

```
           Open-Loop Plant (A, C) & Desired Observer Roots {po,1, ..., po,n}
                                      |
                          Check Observability: rank(Wo) = n?
                                      |
                 +--------------------+--------------------+
                 |                                         |
     Method 1: Canonical Form                 Method 2: Ackermann's Formula
                 |                                         |
     Form Dual Companion Matrices             Evaluate Desired Matrix Polynomial:
     and Target Polynomial alpha_o(s)         alpha_o(A) = A^n + l1*A^(n-1) + ... + ln*I
                 |                                         |
     Solve: L_obs,i = beta_i - a_i            Compute: L = alpha_o(A) * inv(Wo) * [0 ... 1]'
                 |                                         |
     Transform: L = P * L_obs                              |
                 +--------------------+--------------------+
                                      |
                         Resulting Observer Dynamics:
                         \dot{\hat{x}} = (A - LC)\hat{x} + Bu + Ly
```

---

### Method 1: Synthesis in Observable Canonical Form

1. Compute the open-loop characteristic polynomial: $\det(sI - A) = s^n + a_1 s^{n-1} + \dots + a_n$.
2. Define the desired observer characteristic polynomial from target roots ${p_{o,1}, \dots, p_{o,n}}$: $$\alpha_o(s) = (s - p_{o,1})(s - p_{o,2})\dots(s - p_{o,n}) = s^n + \beta_1 s^{n-1} + \dots + \beta_n$$
3. In observable canonical form, $A_{\text{obs}} - L_{\text{obs}}C_{\text{obs}}$ modifies only the first column of the matrix: $$L_{\text{obs}, i} = \beta_i - a_i, \quad i = 1, 2, \dots, n$$
4. Transform back to physical state coordinates using the transformation matrix $P = W_o^{-1} W_{o,\text{obs}}$: $$L = P L_{\text{obs}} = W_o^{-1} W_{o,\text{obs}} L_{\text{obs}}$$

---

### Method 2: Ackermann’s Formula for Observers

For single-output observable systems, applying the duality mapping $(A \to A^T, B \to C^T, K \to L^T)$ to controller Ackermann's formula yields: $$L^T = \begin{bmatrix} 0 & 0 & \dots & 1 \end{bmatrix} W_r(A^T, C^T)^{-1} \alpha_o(A^T)$$

Taking the transpose of both sides (and noting that $W_r(A^T, C^T)^T = W_o(A, C)$ and $\alpha_o(A^T)^T = \alpha_o(A)$) gives: $$L = \alpha_o(A) W_o^{-1} \begin{bmatrix} 0 \ 0 \ \vdots \ 1 \end{bmatrix}$$ where $\alpha_o(A) = A^n + \beta_1 A^{n-1} + \dots + \beta_n I \in \mathbb{R}^{n \times n}$.

---

### Method 3: Computational Synthesis in MATLAB

Using duality, MATLAB's pole-placement functions are called with transposed plant matrices:

```
\% Single-Output systems (order n <= 10)
L = acker(A', C', p_obs)';

\% Multivariable systems or distinct poles (numerically robust)
L = place(A', C', p_obs)';
```

---

### Observer Pole Placement Guidelines & Engineering Trade-offs

The selection of observer poles represents a fundamental trade-off between estimation speed and noise immunity:

- **The Speed Rule of Thumb:** Place observer poles **2 to 5 times (or 2 to 10 times) farther into the left-half plane** than the closed-loop controller poles: $$-\text{Re}(\lambda_{\text{obs}}) > -2 , \text{Re}(\lambda_{\text{ctrl}})$$ _Physical Reasoning:_ The state estimation error must decay significantly faster than the natural response time of the plant. If the observer is too slow, the controller acts on obsolete state estimates, causing phase lag, increased overshoot, and degraded tracking.
- **The Sensor Noise Penalty:** Moving observer poles excessively far to the left requires a very large gain vector $L$. If sensor measurements are corrupted by high-frequency noise $w(t)$ ($y_m = Cx + w$), the innovation term feeds noise directly into the estimator: $$\dot{\hat{x}} = (A - LC)\hat{x} + Bu + L(Cx + w) = (A - LC)\hat{x} + Bu + LCx + Lw(t)$$ Excessive observer gains amplify sensor noise, inducing high-frequency chatter in the actuators and driving the plant into actuator saturation.

### Core Concepts & Formulations

#### Observer-Based Control Architecture

When physical states cannot be measured, the control law substitutes the estimated states $\hat{x}(t)$ in place of the true states $x(t)$: $$u(t) = -K\hat{x}(t) + k_r r(t)$$

```
               +-------------------------------------------------------+
               | Observer-Based Controller                             |
               |                                                       |
               |             +-----+      u                            |
      r ----(kr)------------>|  +  |------------+                      |
               |             |     |            |                      |
               |        /--->|  -  |            |                      |
               |        |    +-----+            |                      |
               |        |                       |                      |
               |     [ -K ]                     v                      |
               |        |              +-----------------+             |
               |      \hat{x}          | \dot{\hat{x}} = |             |
               |        +<-------------| (A-LC)\hat{x}   |<---\        |
               |                       |  + Bu + Ly      |    |        |
               |                       +-----------------+    |        |
               |                                              |        |
               |                                            [ L ]      |
               |                                              |        |
               +----------------------------------------------|--------+
                                                              |  y
                               +---------------+              |
                               | \dot{x}=Ax+Bu |--------------+
                               | y = Cx        |
                               +---------------+
                                    Plant
```

_(Block diagram of the combined observer-controller feedback system)._

#### Augmented Closed-Loop State Dynamics

Since both the plant and the observer are $n$-th order systems, the overall interconnected closed-loop system is of order $2n$. To analyze its eigenvalues, define the transformed state vector grouping the true state $x(t)$ and the estimation error $e(t) = x(t) - \hat{x}(t)$: $$\begin{bmatrix} x(t) \ e(t) \end{bmatrix} = \begin{bmatrix} I & 0 \ I & -I \end{bmatrix} \begin{bmatrix} x(t) \ \hat{x}(t) \end{bmatrix}$$

Express the control law in terms of $x(t)$ and $e(t)$ by substituting $\hat{x} = x - e$: $$u(t) = -K(x(t) - e(t)) + k_r r(t) = -Kx(t) + Ke(t) + k_r r(t)$$

Substitute $u(t)$ into the plant state equation: $$\dot{x}(t) = Ax(t) + B\left( -Kx(t) + Ke(t) + k_r r(t) \right) = (A - BK)x(t) + BKe(t) + B k_r r(t)$$

Combine this with the autonomous error equation $\dot{e}(t) = (A - LC)e(t)$: $$\begin{bmatrix} \dot{x}(t) \ \dot{e}(t) \end{bmatrix} = \begin{bmatrix} A - BK & BK \ 0 & A - LC \end{bmatrix} \begin{bmatrix} x(t) \ e(t) \end{bmatrix} + \begin{bmatrix} B k_r \ 0 \end{bmatrix} r(t)$$ $$y(t) = \begin{bmatrix} C & 0 \end{bmatrix} \begin{bmatrix} x(t) \ e(t) \end{bmatrix}$$

#### Proof of the Separation Principle

Because the augmented system matrix is block upper-triangular, its characteristic determinant splits into the product of the determinants of its diagonal blocks: $$\det \left( sI - \begin{bmatrix} A - BK & BK \ 0 & A - LC \end{bmatrix} \right) = \det(sI - (A - BK)) \cdot \det(sI - (A - LC))$$

> **The Separation Principle (Separation Theorem):** The design of the state feedback gain vector $K$ and the observer gain vector $L$ can be carried out **completely independently**:
> 
> 1. Compute $K$ assuming all states are directly measured to place the controller poles at $\text{eig}(A - BK)$.
> 2. Compute $L$ independently to place the observer error poles at $\text{eig}(A - LC)$.
> 
> The $2n$ closed-loop eigenvalues of the combined system consist simply of the **union of the $n$ controller eigenvalues and the $n$ observer eigenvalues**: $$\Lambda_{\text{closed-loop}} = \text{eig}(A - BK) \cup \text{eig}(A - LC)$$

## 7. Frequency-Domain Realization & Transfer Functions

### Revision Checklist

- [ ] **Identify the poles of the dynamic controller** as the eigenvalues of $(A - BK - LC)$.
- [ ] **Explain why output feedback loses the guaranteed stability margins** (e.g., infinite gain margin, $\pm 60^\circ$ phase margin) of pure state feedback.

---

### Core Concepts & Formulations

#### Derivation of the Dynamic Controller Transfer Function

To express the observer-based controller as a classical transfer function block, substitute the control law $u(t) = -K\hat{x}(t) + k_r r(t)$ into the observer differential equation: $$\dot{\hat{x}}(t) = (A - LC)\hat{x}(t) + B(-K\hat{x}(t) + k_r r(t)) + Ly(t)$$ $$\dot{\hat{x}}(t) = (A - BK - LC)\hat{x}(t) + B k_r r(t) + Ly(t)$$

Taking the Laplace transform with zero initial conditions ($\hat{x}(0) = 0$): $$(sI - (A - BK - LC))\hat{X}(s) = B k_r R(s) + L Y(s)$$ $$\hat{X}(s) = (sI - (A - BK - LC))^{-1} B k_r R(s) + (sI - (A - BK - LC))^{-1} L Y(s)$$

Substitute $\hat{X}(s)$ into the control law $U(s) = -K\hat{X}(s) + k_r R(s)$: $$U(s) = \left[ k_r - K(sI - A + BK + LC)^{-1} B k_r \right] R(s) - \left[ K(sI - A + BK + LC)^{-1} L \right] Y(s)$$

This produces the **Two-Degree-of-Freedom (2-DOF)** controller structure: $$U(s) = G_{ur}(s)R(s) - C_{\text{ctrl}}(s)Y(s)$$

```
             r(s) ----> [ Gur(s) ] ----+
                                       |
                                       v
                                +-----( + )----> u(s) ---->[ P(s) ]----+----> y(s)
                                |                                     |
                                |                                     |
                                +------[ C_ctrl(s) ]<-----------------+
```

_(Classical 2-DOF unity feedback representation of observer-based control)._

The feedback compensator transfer function is: $$C_{\text{ctrl}}(s) = K \left( sI - (A - BK - LC) \right)^{-1} L$$

- **Controller Poles:** The poles of $C_{\text{ctrl}}(s)$ are the eigenvalues of $(A - BK - LC)$. While $(A - BK)$ and $(A - LC)$ are individually designed to be stable, the matrix $(A - BK - LC)$ is not constrained to be stable; therefore, **an observer-based controller may itself be open-loop unstable** while still stabilizing the plant.
- **Loss of Guaranteed Robustness Margins:** Pure Linear Quadratic Regulator (LQR) full-state feedback possesses guaranteed infinite gain margin and at least $\pm 60^\circ$ of phase margin. However, as proven by John Doyle (1978), **these robust stability margins are completely lost when estimated states $\hat{x}$ from an observer replace physical states**. Consequently, loop transfer recovery (LTR) and frequency-domain margin verification are essential in output feedback design.

### Core Concepts & Formulations

#### Stochastic System Formulation

When plant disturbances $v(t)$ and sensor measurement noise $w(t)$ are modeled as zero-mean, uncorrelated Gaussian white noise processes: $$\dot{x}(t) = Ax(t) + Bu(t) + v(t), \quad y(t) = Cx(t) + w(t)$$ $$\mathbb{E}[v(t)v^T(\tau)] = R_v \delta(t - \tau), \quad \mathbb{E}[w(t)w^T(\tau)] = R_w \delta(t - \tau), \quad \mathbb{E}[v(t)w^T(\tau)] = 0$$ where $R_v \ge 0$ is the process noise covariance matrix and $R_w > 0$ is the sensor noise covariance matrix.

#### The Kalman-Bucy Filter

Rather than choosing observer poles heuristically, the **Kalman Filter** computes the observer gain $L$ that minimizes the steady-state mean-squared estimation error: $$J = \lim_{t \to \infty} \mathbb{E}\left[ |x(t) - \hat{x}(t)|^2 \right] = \text{Tr}(P)$$

The optimal steady-state observer gain is: $$L = P C^T R_w^{-1}$$ where $P = P^T > 0$ is the estimation error covariance matrix ($P = \mathbb{E}[e(t)e^T(t)]$), obtained as the unique positive-definite solution to the **Filter Algebraic Riccati Equation (FARE)**: $$AP + PA^T - PC^T R_w^{-1} C P + R_v = 0$$

In MATLAB, this gain is computed via:

```
[L, P] = lqe(A, eye(n), C, Rv, Rw);
```

Combining LQR state feedback with the Kalman filter forms the **Linear Quadratic Gaussian (LQG)** controller, which preserves the Separation Principle in the presence of stochastic noise.

## 9. Summary Comparison Table: Reachability vs. Observability

| Feature / Property             | Reachability / State Feedback ($u = -Kx$)                               | Observability / State Estimator ($\dot{\hat{x}} = (A-LC)\hat{x} + \dots$)    |
| :----------------------------- | :---------------------------------------------------------------------- | :--------------------------------------------------------------------------- |
| **Physical Objective**         | Steer states from any $x_0$ to any $x_f$ using input $u(t)$.            | Reconstruct internal state $x(t)$ using $u(t)$ and output $y(t)$.            |
| **System Pair**                | Matrix pair $(A, B)$.                                                   | Matrix pair $(A, C)$.                                                        |
| **Fundamental Matrix**         | $W_r = \begin{bmatrix} B & AB & \dots & A^{n-1}B \end{bmatrix}$.        | $W_o = \begin{bmatrix} C^T & (CA)^T & \dots & (CA^{n-1})^T \end{bmatrix}^T$. |
| **Full Rank Condition**        | $\text{rank}(W_r) = n \iff \det(W_r) \neq 0$.                           | $\text{rank}(W_o) = n \iff \det(W_o) \neq 0$.                                |
| **Dual Pair Equivalence**      | $(A, B)$ reachable $\iff (A^T, B^T)$ observable.                        | $(A, C)$ observable $\iff (A^T, C^T)$ reachable.                             |
| **Governing Dynamics**         | Closed-loop plant modes: $(A - BK)$.                                    | Estimation error modes: $(A - LC)$.                                          |
| **Design Formula (Ackermann)** | $K = \begin{bmatrix} 0 & \dots & 1 \end{bmatrix} W_r^{-1} \alpha_d(A)$. | $L = \alpha_o(A) W_o^{-1} \begin{bmatrix} 0 & \dots & 1 \end{bmatrix}^T$.    |
| **MATLAB Synthesis**           | `K = acker(A, B, p)` / `place(A, B, p)`.                                | `L = acker(A', C', p)'` / `place(A', C', p)'`.                               |
| **Combined System Roots**      | Contributes $n$ closed-loop poles via $\det(sI - (A - BK))$.            | Contributes $n$ closed-loop poles via $\det(sI - (A - LC))$.                 |
