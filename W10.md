## 1. Frequency Response of Linear Time-Invariant (LTI) Systems

### Revision Checklist

- [ ] **Define the frequency response** of a stable LTI system subjected to a sinusoidal input.
- [ ] **Derive the steady-state output sinusoid** in terms of magnitude gain $|G(j\omega)|$ and phase shift $\angle G(j\omega)$.
- [ ] **Explain why frequency response evaluation** $s = j\omega$ requires system stability.
- [ ] **Distinguish between minimum-phase and non-minimum-phase systems** regarding magnitude curves, phase lag, and right-half-plane (RHP) singularities.

---

### Core Concepts & Formulations

#### Steady-State Sinusoidal Response

For a continuous-time, stable LTI system with transfer function $G(s)$, applying a pure sinusoidal input signal: $$u(t) = A_u \cos(\omega t + \phi) \quad$$ yields an unforced natural response that decays asymptotically to zero, leaving a steady-state forced response that is an amplified and phase-shifted sinusoid of the **exact same radian frequency** $\omega$: $$y_{ss}(t) = A_u |G(j\omega)| \cos\big(\omega t + \phi + \angle G(j\omega)\big) \quad$$

- **Magnitude (Gain):** $|G(j\omega)| = \sqrt{\text{Re}[G(j\omega)]^2 + \text{Im}[G(j\omega)]^2}$, representing the amplification ratio of output amplitude to input amplitude at frequency $\omega$.
- **Phase Shift (Argument):** $\angle G(j\omega) = \arctan\left(\frac{\text{Im}[G(j\omega)]}{\text{Re}[G(j\omega)]}\right)$, quantifying the time lead or time lag between output and input cycles.
- **Analytical Basis:** Evaluating $G(s)$ on the imaginary axis ($s = j\omega$) corresponds to evaluating the Fourier transform of the system's impulse response. If a system possesses unstable poles ($\text{Re}(p) \ge 0$), no steady-state sinusoidal response exists because the transient output diverges to infinity.

#### Minimum-Phase vs. Non-Minimum-Phase Systems

- **Minimum-Phase Systems:** Systems having all poles and zeros strictly confined to the open left-half complex plane ($\text{Re}(s) < 0$). For minimum-phase systems, the magnitude response $|G(j\omega)|$ uniquely determines the phase curve $\angle G(j\omega)$ via Bode's gain-phase relationship.
- **Non-Minimum-Phase Systems:** Systems containing **right-half-plane zeros** ($s = +z_0$), **right-half-plane poles**, or **pure transport delays** ($e^{-s\tau}$).
    - _Phase Penalty:_ While an RHP zero ($s - z_0$) provides the exact same magnitude contribution as an LHP zero ($s + z_0$), it introduces severe **phase lag** ($-90^\circ$ instead of $+90^\circ$).
    - _Time Delays:_ A pure delay $e^{-s\tau}$ possesses unity gain ($|e^{-j\omega\tau}| = 1$) at all frequencies but introduces a linearly declining phase lag $\angle(e^{-j\omega\tau}) = -\omega \tau$ (in radians), rapidly eroding phase margin at higher frequencies.

## 2. Bode Plots & Asymptotic Approximations

### Revision Checklist

- [ ] **Identify the slope and constant phase** of pure integrators ($s^{-1}$) and differentiators ($s$).
- [ ] **State the asymptotic corner frequency rules** for first-order factors $(1 + s/a)$ and $(1 + s/a)^{-1}$.
- [ ] **Characterize second-order underdamped factors**, including natural frequency $\omega_n$, high-frequency roll-off ($-40\text{ dB/decade}$), and resonance peaking governed by $\zeta$.
- [ ] **Formulate the composite Bode sketching procedure** by summing individual pole and zero asymptotic slopes.

---

### Core Concepts & Formulations

#### Logarithmic Scaling & Decibel Representation

A Bode diagram plots two separate curves against frequency $\omega$ on a logarithmic horizontal scale:

1. **Magnitude Plot:** Logarithmic gain expressed in decibels: $$|G(j\omega)|_{\text{dB}} = 20 \log_{10}|G(j\omega)| \quad$$
2. **Phase Plot:** Phase angle $\angle G(j\omega)$ plotted linearly in degrees (or radians) against $\log_{10}\omega$.

Factoring a general rational transfer function into standard Bode form: $$G(s) = K_0 \frac{\prod (1 + s/z_i)}{s^m \prod (1 + s/p_j) \prod (1 + 2\zeta_k s/\omega_{n,k} + s^2/\omega_{n,k}^2)} \quad$$ multiplication of terms converts into straightforward algebraic addition of decibels and phase angles: $$20\log_{10}|G(j\omega)| = 20\log_{10}|K_0| + \sum 20\log_{10}|1 + j\omega/z_i| - \sum 20\log_{10}|1 + j\omega/p_j| - \dots \quad$$ $$\angle G(j\omega) = \sum \angle(1 + j\omega/z_i) - m(90^\circ) - \sum \angle(1 + j\omega/p_j) - \dots \quad$$

#### Asymptotic Slopes for Elementary Factors

|Transfer Function Component|Magnitude Asymptote Slope|Phase Behavior|Key Corner / Break Frequency|
|:--|:--|:--|:--|
|**Constant Gain $K$**|Flat ($0\text{ dB/decade}$)|$0^\circ$ (if $K>0$) or $-180^\circ$ (if $K<0$)|None|
|**Integrator $1/s$**|Constant $-20\text{ dB/decade}$|Constant $-90^\circ$|Passes $0\text{ dB}$ at $\omega = 1\text{ rad/s}$|
|**Differentiator $s$**|Constant $+20\text{ dB/decade}$|Constant $+90^\circ$|Passes $0\text{ dB}$ at $\omega = 1\text{ rad/s}$|
|**First-Order Zero $(1 + s/z_0)$**|$0\text{ dB}$ for $\omega < z_0$; $+20\text{ dB/dec}$ for $\omega > z_0$|$0^\circ \to +45^\circ \text{ at } z_0 \to +90^\circ$ ($+45^\circ/\text{dec}$)|Corner at $\omega = z_0$|
|**First-Order Pole $(1 + s/p_0)^{-1}$**|$0\text{ dB}$ for $\omega < p_0$; $-20\text{ dB/dec}$ for $\omega > p_0$|$0^\circ \to -45^\circ \text{ at } p_0 \to -90^\circ$ ($-45^\circ/\text{dec}$)|Corner at $\omega = p_0$|
|**Quadratic Pole Pair** $\left(1 + \frac{2\zeta s}{\omega_n} + \frac{s^2}{\omega_n^2}\right)^{-1}$|$0\text{ dB}$ for $\omega < \omega_n$; $-40\text{ dB/dec}$ for $\omega > \omega_n$|$0^\circ \to -90^\circ \text{ at } \omega_n \to -180^\circ$ ($-90^\circ/\text{dec}$)|Corner at natural frequency $\omega_n$|

#### Second-Order Underdamped Corrections & Resonance

For complex poles with low damping ratio ($\zeta < 0.707$), the actual magnitude deviates sharply from straight-line asymptotes near $\omega_n$:

- **Exact Break Magnitude Correction:** At $\omega = \omega_n$, the normalized magnitude is: $$|G(j\omega_n)| = \frac{1}{2\zeta} \implies 20\log_{10}\left(\frac{1}{2\zeta}\right) = -20\log_{10}(2\zeta)\text{ dB} \quad$$
- **Resonant Peak Value ($M_r$):** Occurs at the resonant frequency $\omega_r = \omega_n \sqrt{1 - 2\zeta^2}$ (for $\zeta < 1/\sqrt{2}$): $$M_r = \frac{1}{2\zeta \sqrt{1 - \zeta^2}}$$ Sharp resonance peaks indicate low damping and correlate with large overshoot or oscillations in transient time responses.

## 3. The "Gang of Four" Sensitivity Functions

### Revision Checklist

- [ ] **Draw the block diagram** of a standard single-loop feedback system with plant $P(s)$, controller $C(s)$, load disturbance $v$, measurement noise $w$, and reference $r$.
- [ ] **Define the loop transfer function** $L(s) = P(s)C(s)$.
- [ ] **Formulate the Sensitivity Function** $S(s) = \frac{1}{1 + L(s)}$ and state its physical roles (error sensitivity, disturbance attenuation, plant perturbation robustness).
- [ ] **Formulate the Complementary Sensitivity Function** $T(s) = \frac{L(s)}{1 + L(s)}$ and verify the algebraic identity $S(s) + T(s) = 1$.
- [ ] **Formulate the Load Disturbance Sensitivity** $PS(s) = \frac{P(s)}{1 + L(s)}$ and explain how integral action forces $PS(0) = 0$.
- [ ] **Formulate the Noise / Control Sensitivity** $CS(s) = \frac{C(s)}{1 + L(s)}$ and explain why controller roll-off is vital to protect actuators.

---

### Core Concepts & Formulations

#### Feedback System Architecture

Consider the standard unity-feedback configuration subjected to all three primary physical operational inputs:

```
                     Load Disturbance v
                             |
                             v
   r       e      +----+  u  +    \mu  +----+  \eta  +    y
  --->(+)-------->|C(s)|---->(+)------>|P(s)|------>(+)----->
       ^ -        +----+               +----+        ^ +
       |                                             |
       +---------------------------------------------+
                             ^
                             |
                    Measurement Noise w
```

_(Standard feedback loop with load disturbance $v$ at the plant input, measurement noise $w$ at the sensor output, and reference setpoint $r$)._

The open-loop transfer function is: $$L(s) = P(s)C(s) \quad$$

Applying superposition across all three external driving signals $(r, v, w)$ yields the fundamental algebraic relationships for error $e = r - y$, control effort $u$, and system output $y$:

$$\begin{aligned} y(s) &= \left(\frac{PC}{1 + PC}\right) r + \left(\frac{P}{1 + PC}\right) v + \left(\frac{1}{1 + PC}\right) w \quad \ e(s) &= \left(\frac{1}{1 + PC}\right) r - \left(\frac{P}{1 + PC}\right) v - \left(\frac{1}{1 + PC}\right) w \quad \ u(s) &= \left(\frac{C}{1 + PC}\right) r - \left(\frac{PC}{1 + PC}\right) v - \left(\frac{C}{1 + PC}\right) w \quad \end{aligned}$$

The **Gang of Four** represents the four central closed-loop transfer functions governing system performance and robustness:

```
+------------------------------------+---------------------------------------+
|  Sensitivity Function:             |  Complementary Sensitivity Function:  |
|      S(s) = 1 / (1 + PC)           |          T(s) = PC / (1 + PC)         |
|  - Maps reference r to error e     |  - Maps reference r to output y       |
|  - Maps output disturbance to y    |  - Maps sensor noise w to output y    |
+------------------------------------+---------------------------------------+
|  Load Disturbance Sensitivity:     |  Noise / Control Sensitivity:         |
|      PS(s) = P / (1 + PC)          |          CS(s) = C / (1 + PC)         |
|  - Maps input disturbance v to y   |  - Maps sensor noise w to actuator u  |
|  - Governs load rejection          |  - Maps reference r to control u      |
+------------------------------------+---------------------------------------+
```

_(The Gang of Four sensitivity transfer functions)._

---

### Detailed Analysis of Each Sensitivity Function

#### 1. Sensitivity Function: $S(s) = \frac{1}{1 + P(s)C(s)} = \frac{1}{1 + L(s)}$

- **Tracking Error Transmission:** Relates reference $r$ to tracking error $e$: $E(s)/R(s) = S(s)$. When $|S(j\omega)| \ll 1$, tracking error is small and the system tracks commands accurately.
- **Output Disturbance Attenuation:** Relates disturbances injected at the output sensor to the measured output: $Y(s)/W(s) = S(s)$. At frequencies where $|S(j\omega)| < 1$, disturbances are actively attenuated by feedback; where $|S(j\omega)| > 1$, disturbances are amplified.
- **Robustness to Plant Variations:** Quantifies the fractional change in closed-loop transfer function $G_{cl} = T$ relative to a fractional perturbation in the physical plant model $P$: $$\frac{dG_{cl}}{G_{cl}} = S(s) \frac{dP}{P} \quad$$ Small sensitivity $|S(j\omega)|$ shields closed-loop dynamics from plant parameter variations and unmodeled dynamics.

#### 2. Complementary Sensitivity Function: $T(s) = \frac{P(s)C(s)}{1 + P(s)C(s)} = \frac{L(s)}{1 + L(s)}$

- **Reference Tracking:** Direct closed-loop transfer function from reference $r$ to plant output $y$: $Y(s)/R(s) = T(s)$ (assuming unity feedback).
- **Sensor Noise Injection:** Relates measurement noise $w$ to output $y$. To prevent high-frequency sensor noise from corrupting system outputs, $|T(j\omega)|$ must roll off sharply at high frequencies ($|T(j\omega)| \to 0$).
- **The Complementary Identity:** Adding $S(s)$ and $T(s)$ yields the fundamental algebraic constraint: $$S(s) + T(s) = \frac{1}{1 + L(s)} + \frac{L(s)}{1 + L(s)} = \frac{1 + L(s)}{1 + L(s)} \equiv 1 \quad$$ This identity proves that **$S(j\omega)$ and $T(j\omega)$ cannot be made simultaneously small at the same frequency**.

#### 3. Load Disturbance Sensitivity Function: $PS(s) = \frac{P(s)}{1 + P(s)C(s)} = P(s)S(s)$

- **Input Disturbance Rejection:** Governs how disturbances $v$ entering at the actuator/plant input propagate to the output $y$: $Y(s)/V(s) = PS(s)$.
- **Impact of Integral Action:** If the plant has finite DC gain ($P(0) \neq 0$) and the controller includes pure integral action ($C(s) \approx k_i/s$ as $s \to 0$), then: $$PS(s) = \frac{P(s)}{1 + P(s)(k_i/s)} = \frac{s P(s)}{s + k_i P(s)} \implies PS(0) = 0 \quad$$ Integral action forces $PS(0) = 0$, guaranteeing zero steady-state error under constant step load disturbances.

#### 4. Noise / Control Sensitivity Function: $CS(s) = \frac{C(s)}{1 + P(s)C(s)} = C(s)S(s)$

- **Actuator Noise Transmission:** Maps high-frequency sensor noise $w$ directly into actuator control signals: $U(s)/W(s) = -CS(s)$.
- **Actuator Effort for Reference Commands:** Governs the control effort required to track references: $U(s)/R(s) = CS(s)$.
- **High-Frequency Roll-Off Requirement:** At high frequencies, physical loop gain drops ($|L(j\omega)| \to 0 \implies S(j\omega) \to 1$), reducing noise sensitivity to the controller itself: $$\lim_{\omega \to \infty} CS(j\omega) \approx C(j\omega) \quad$$ If a controller uses unfiltered derivative action ($C(s) \approx K_d s$), $|C(j\omega)| \to \infty$ as $\omega \to \infty$, causing noise sensitivity to explode. This amplifies sensor noise into high-frequency actuator chatter, leading to excessive wear and actuator saturation. Practical controllers must incorporate low-pass derivative filtering to ensure $C(s)$ rolls off at high frequencies.

## 4. Two-Degree-of-Freedom (2-DOF) Architecture & The "Gang of Six"

### Revision Checklist

- [ ] **Draw the block diagram** of a 2-DOF architecture incorporating a feedforward prefilter $F(s)$.
- [ ] **List the six transfer functions** composing the "Gang of Six".
- [ ] **Explain how feedforward prefilter $F(s)$ decouples** reference tracking from disturbance attenuation and robustness.

---

### Core Concepts & Formulations

#### The 2-DOF Architecture

In a standard single-degree-of-freedom unity-feedback loop ($F(s) = 1$), the feedback compensator $C(s)$ must simultaneously manage reference tracking, load disturbance rejection, noise attenuation, and model uncertainty. Introducing a feedforward filter $F(s)$ on the reference command yields the **Two-Degree-of-Freedom (2-DOF)** structure:

```
             +------+  ym   +----+  e   +----+  u  +    \mu  +----+  \eta  +   y
   r ------->| F(s) |----->(+)--------->|C(s)|---->(+)------>|P(s)|------>(+)---->
             +------+       ^ -         +----+               +----+        ^ +
                            |                                              |
                            +----------------------------------------------+
                                                  ^
                                                  |
                                         Measurement Noise w
```

_(Two-Degree-of-Freedom feedback control architecture)._

#### The Gang of Six Transfer Matrix

The complete system input-output behavior across external inputs $(r, v, w)$ is governed by the **Gang of Six**:

$$\begin{bmatrix} y \ u \end{bmatrix} = \begin{bmatrix} G_{yr}(s) & G_{yv}(s) & G_{yw}(s) \ G_{ur}(s) & G_{uv}(s) & G_{uw}(s) \end{bmatrix} \begin{bmatrix} r \ v \ w \end{bmatrix} \quad$$

$$\begin{aligned} G_{yr}(s) &= \frac{P(s)C(s)F(s)}{1 + P(s)C(s)} = F(s)T(s) \quad & G_{yv}(s) &= \frac{P(s)}{1 + P(s)C(s)} = PS(s) \quad & G_{yw}(s) &= \frac{1}{1 + P(s)C(s)} = S(s) \quad \ G_{ur}(s) &= \frac{C(s)F(s)}{1 + P(s)C(s)} = F(s)CS(s) \quad & G_{uv}(s) &= -\frac{P(s)C(s)}{1 + P(s)C(s)} = -T(s) \quad & G_{uw}(s) &= -\frac{C(s)}{1 + P(s)C(s)} = -CS(s) \quad \end{aligned}$$

- **Design Strategy:** The feedback compensator $C(s)$ is synthesized first to optimize the **Gang of Four** ($S, T, PS, CS$), securing internal stability, robust margins, disturbance rejection, and noise filtering. The prefilter $F(s)$ is then designed independently to shape reference tracking ($G_{yr} = FT$) without degrading feedback loop robustness.

## 5. Fundamental Design Trade-offs & Loop Shaping

### Revision Checklist

- [ ] **State the algebraic constraint** $S(j\omega) + T(j\omega) = 1$ and its operational consequences across frequency bands.
- [ ] **Define the gain crossover frequency** $\omega_{gc}$ and explain its relationship to system bandwidth.
- [ ] **Formulate low-frequency loop shaping objectives**: $|L(j\omega)| \gg 1$ for reference tracking and disturbance rejection.
- [ ] **Formulate high-frequency loop shaping objectives**: $|L(j\omega)| \ll 1$ for sensor noise attenuation and robustness.
- [ ] **State the crossover slope requirement** (approximately $-20\text{ dB/decade}$) to guarantee adequate phase margin.

---

### Core Concepts & Engineering Trade-offs

#### The Fundamental Loop Shaping Dilemma

Control system design in the frequency domain involves shaping the open-loop transfer function $L(j\omega) = P(j\omega)C(j\omega)$ to manage conflicting requirements across different frequency regimes:

```
  Magnitude (dB)
     ^
     |  Low-Frequency Band:                  High-Frequency Band:
     |  |L(jw)| >> 1                         |L(jw)| << 1
     |  S(jw) ~ 0  => Good Tracking          T(jw) ~ 0  => Noise Filtering
     |  PS(jw) ~ 0 => Disturbance Rejection  CS(jw) ~ 0 => Actuator Protection
     |  \
     |   \
     |    \  Slope near crossover ~ -20 dB/dec
  0dB+-----\----------------------------------------> Frequency w
     |      \           w_gc
     |       \
     |        \
     v         \
```

_(Frequency-domain loop shaping objectives across operational bands)._

#### Operational Regimes Across Frequency

|Operational Frequency Band|Loop Gain Requirement|Resulting Sensitivity Behavior|Engineering Objective Achieved|
|:--|:--|:--|:--|
|**Low Frequencies** ($\omega \ll \omega_{gc}$)|**High Loop Gain:** $\lvert L(j\omega)\rvert \gg 1$|$S \approx 0$, $T \approx 1$, $PS \approx 0$|Accurate reference tracking and load-disturbance rejection.|
|**Mid Frequencies** ($\omega \approx \omega_{gc}$)|**Controlled Transition:** $\lvert L(j\omega)\rvert \approx 1$ ($0\text{ dB}$)|$\lvert S\rvert$ peaks at $M_s < 2$; loop slope near $-20\text{ dB/decade}$|Adequate phase margin and stability margin $s_m$; well-damped closed loop.|
|**High Frequencies** ($\omega \gg \omega_{gc}$)|**Low Loop Gain:** $\lvert L(j\omega)\rvert \ll 1$|$S \approx 1$, $T \approx 0$, $CS$ small|Sensor-noise attenuation, actuator protection, and robustness to unmodeled dynamics.|

- **Bode's Gain-Phase Relationship Constraint:** To maintain closed-loop stability, the gain curve cannot drop arbitrarily steeply at crossover. A slope of $-20\text{ dB/decade}$ near $\omega_{gc}$ yields a phase lag of roughly $-90^\circ$ (leaving a healthy $+90^\circ$ phase margin). If the loop gain drops at $-40\text{ dB/decade}$ through crossover, phase lag approaches $-180^\circ$, causing phase margin to collapse to near zero and destabilizing the feedback loop.

## 6. Internal Stability & Hidden Instabilities (Pole-Zero Cancellations)

### Revision Checklist

- [ ] **State the definition of internal stability** for a feedback loop in terms of all four Gang of Four transfer functions.
- [ ] **Explain why stability of the loop transfer function** $L(s) = P(s)C(s)$ does not guarantee closed-loop internal stability.
- [ ] **Analyze the hazard of RHP pole-zero cancellations** between plant and controller using the canonical counterexample.
- [ ] **Explain why unstable plant poles must never be cancelled** by controller zeros.

---

### Core Concepts & Formulations

#### Definition of Internal Closed-Loop Stability

A feedback control system is **internally stable** if and only if **all four transfer functions in the Gang of Four are stable** (possess no poles in the closed right-half complex plane, $\text{Re}(s) \ge 0$). Because all four functions share the exact same characteristic denominator: $$D_{cl}(s) = 1 + P(s)C(s) = 1 + L(s) \quad$$ the closed-loop system is stable under normal conditions if and only if the roots of $1 + P(s)C(s) = 0$ lie strictly in the open left-half plane.

#### The Danger of RHP Pole-Zero Cancellations

Evaluating only the scalar loop transfer function $L(s) = P(s)C(s)$ or the complementary sensitivity $T(s)$ can conceal internal instability when pole-zero cancellations occur between $P(s)$ and $C(s)$ in the right-half plane.

#### Canonical Illustrative Example

Consider an open-loop unstable plant controlled by a PI controller designed to cancel the unstable pole: $$P(s) = \frac{1}{s - a} \quad (a > 0), \quad C(s) = \frac{k(s - a)}{s} \quad$$

Computing the open-loop transfer function reveals an apparent algebraic cancellation of the unstable factor $(s - a)$: $$L(s) = P(s)C(s) = \left(\frac{1}{s - a}\right) \left(\frac{k(s - a)}{s}\right) = \frac{k}{s} \quad$$

Evaluating the sensitivity functions: $$S(s) = \frac{1}{1 + k/s} = \frac{s}{s + k} \quad$$ $$T(s) = \frac{k/s}{1 + k/s} = \frac{k}{s + k} \quad$$ Both $L(s)$, $S(s)$, and $T(s)$ appear stable for any $k > 0$. However, evaluating the **Load Disturbance Sensitivity** $PS(s)$ reveals the hidden instability: $$PS(s) = \frac{P(s)}{1 + P(s)C(s)} = \frac{\frac{1}{s - a}}{1 + \frac{k}{s}} = \frac{s}{(s - a)(s + k)} \quad$$

- **Physical Failure:** The transfer function $PS(s)$ retains the unstable open-loop pole at $s = +a$. Any non-zero load disturbance $v(t)$ at the plant input—such as a small wind gust or thermal fluctuation—excites this unobservable mode, causing the true plant output $y(t)$ to grow exponentially without bound.
- **Core Design Rule:** **Never cancel unstable plant poles with controller zeros, and never cancel unstable plant zeros with controller poles**.

## 7. Peak Sensitivity ($M_s$), Stability Margin ($s_m$), and Robustness

### Revision Checklist

- [ ] **Define maximum sensitivity** $M_s = \max_\omega |S(j\omega)|$ and maximum complementary sensitivity $M_t = \max_\omega |T(j\omega)|$.
- [ ] **Formulate the stability margin** $s_m = 1/M_s$ as the shortest Euclidean distance from the Nyquist plot to the critical point $-1$.
- [ ] **Explain why $s_m$ provides a more comprehensive robustness metric** than classical gain and phase margins ($g_m, \phi_m$).
- [ ] **State the practical engineering bounds** for $M_s$ (typically $M_s < 1.5 - 2.0$, corresponding to $s_m > 0.5$).

---

### Core Concepts & Formulations

#### Peak Sensitivity ($M_s$) and the Critical Distance

In the complex plane, the distance from any point on the loop frequency response $L(j\omega)$ to the critical instability point $-1 + j0$ is given by $|1 + L(j\omega)|$:

```
                 Im
                  ^
                  |         Nyquist Curve L(jw)
                  |          \
                  |           \
                  |            * L(jw_ms)
                  |           /
       -1         |   sm     /
      --+---------+---------+---------> Re
        |  \      |        /
        |   \     |       /
        |    \----+------/
        |      |1 + L|
```

_(Geometric relationship between the stability margin $s_m$ and the critical point $-1$)._

From the definition of the sensitivity function: $$|S(j\omega)| = \frac{1}{|1 + L(j\omega)|} \quad$$ The peak value of the sensitivity function, denoted **maximum sensitivity** $M_s$, occurs at the frequency $\omega_{ms}$ where $L(j\omega)$ makes its closest approach to $-1$: $$M_s = \max_{\omega} |S(j\omega)| = \frac{1}{\min_{\omega} |1 + L(j\omega)|} = \frac{1}{s_m} \quad$$

where $s_m = \min_\omega |1 + L(j\omega)|$ is the **stability margin**.

#### Why $s_m$ Beats Classical Gain and Phase Margins

Classical Gain Margin ($g_m$) measures distance along the negative real axis when phase lag is $-180^\circ$. Phase Margin ($\phi_m$) measures distance along the unit circle when loop gain is $0\text{ dB}$.

- **The Vulnerability:** Gain and phase margins evaluate perturbations independently (pure gain change _or_ pure phase lag). A Nyquist plot can pass dangerously close to $-1$ in the third quadrant between the axes, resulting in high gain and phase margins despite being near instability.
- **The Robustness Metric:** The stability margin $s_m$ bounds simultaneous perturbations in both gain and phase. A system designed with $M_s \le 2$ ($s_m \ge 0.5$) is guaranteed to possess: $$g_m \ge \frac{M_s}{M_s - 1} \ge 2 \quad (6\text{ dB}), \quad \phi_m \ge 2\arcsin\left(\frac{1}{2M_s}\right) \ge 29^\circ \quad$$ Typically, control engineers target $M_s \in [1.3, 1.8]$ to guarantee robust stability across all operating regimes.

## 8. Summary Comparison of the Gang of Four

|Transfer Function|Mathematical Definition|Primary Input $\to$ Output Channel|High Gain at Frequency $\omega$ Implies|Ideal Shaping Profile Across Frequency|
|:--|:--|:--|:--|:--|
|**Sensitivity Function $S(s)$**|$\frac{1}{1 + P(s)C(s)}$|Reference $r \to$ Tracking Error $e$ Output Noise $w \to$ Output $y$|Large tracking errors, amplification of disturbances, poor robustness.|**Small at low $\omega$** ($S \approx 0$); bounded peak ($M_s < 2$) at crossover; rises to $1$ at high $\omega$.|
|**Complementary Sensitivity $T(s)$**|$\frac{P(s)C(s)}{1 + P(s)C(s)}$|Reference $r \to$ Output $y$ Sensor Noise $w \to$ Output $y$|Accurate setpoint tracking ($y \approx r$), but passes sensor noise to output.|**Unity at low $\omega$** ($T \approx 1$); rolls off sharply to $0$ at high $\omega$ for noise rejection.|
|**Load Sensitivity $PS(s)$**|$\frac{P(s)}{1 + P(s)C(s)}$|Plant Input Disturbance $v \to$ Output $y$|Large output deflection under external load disturbances.|**Must be forced to zero at DC** via integral action ($PS(0) = 0$); small across disturbance bandwidth.|
|**Noise Sensitivity $CS(s)$**|$\frac{C(s)}{1 + P(s)C(s)}$|Sensor Noise $w \to$ Control Signal $u$ Reference $r \to$ Control Effort $u$|Dangerous high-frequency actuator chatter, wear, and saturation.|**Small at high $\omega$** achieved via controller roll-off and derivative filtering; moderate at mid-frequencies.|

## 9. MATLAB Implementation for Frequency-Domain Analysis

```
% Define Plant and Controller Transfer Functions
s = tf('s');
P = 1 / (s * (s + 2));              % Example 2nd-order plant
C = 5 * (s + 1) / (s + 10);          % Lead-lag / filtered compensator

% Define Open-Loop Loop Transfer Function
L = P * C;

% Construct the Gang of Four
S  = feedback(1, L);                 % S  = 1 / (1 + L)
T  = feedback(L, 1);                 % T  = L / (1 + L)
PS = feedback(P, C);                 % PS = P / (1 + PC)
CS = feedback(C, P);                 % CS = C / (1 + PC)

% Generate Composite Gang of Four Bode Plots
figure;
subplot(2,2,1); bode(S);  grid on; title('Sensitivity S(s)');
subplot(2,2,2); bode(T);  grid on; title('Complementary Sensitivity T(s)');
subplot(2,2,3); bode(PS); grid on; title('Load Sensitivity PS(s)');
subplot(2,2,4); bode(CS); grid on; title('Noise Sensitivity CS(s)');

% Calculate Stability Margins & Peak Sensitivity
[Gm, Pm, Wcg, Wcp] = margin(L);
Ms = norm(S, Inf);                   % Peak magnitude of Sensitivity
sm = 1 / Ms;                         % Stability Margin
fprintf('Gain Margin: %.2f dB, Phase Margin: %.2f deg\n', 20*log10(Gm), Pm);
fprintf('Peak Sensitivity Ms: %.2f, Stability Margin sm: %.2f\n', Ms, sm);
```
