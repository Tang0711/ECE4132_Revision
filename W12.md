## 1. Passivity in Control Systems & Frequency-Domain Implications

### Revision Checklist

- [ ] **Identify physical examples** of passive physical plants (e.g., $RC$ filters, mass-spring-damper systems with friction).
- [ ] **State the Nyquist plane condition** for a passive open-loop transfer function ($\text{Re}[L(j\omega)] \ge 0$).
- [ ] **Prove geometrically and algebraically** why passivity guarantees $|S(j\omega)| \le 1$ (and $M_s \le 1$) for all frequencies.
- [ ] **Explain why passive loops completely avoid** the "waterbed effect" and high-sensitivity peaking ($M_s > 1$).

---

### Core Concepts & Formulations

#### Physical Definition of Passivity

A dynamical system is **passive** if it cannot produce net internal energy. It can only store or dissipate energy supplied by external sources.

- **Physical Examples:** Passive electrical networks containing only resistors, inductors, and capacitors ($RLC$), fluidic flow dampers, and mechanical networks containing mass, stiffness, and friction.
- **Positive Real Property:** The transfer function $L(s)$ of a linear time-invariant passive system is _positive real_, satisfying: $$\text{Re}[L(s)] \ge 0 \quad \text{for all } s \text{ with } \text{Re}(s) \ge 0$$

#### Frequency-Domain and Nyquist Interpretation

For any passive open-loop loop transfer function $L(s)$, the frequency response curve $L(j\omega)$ is strictly confined to the **closed right-half of the complex plane** for all frequencies $\omega \in (-\infty, +\infty)$: $$\text{Re}[L(j\omega)] \ge 0, \quad \forall \omega \in \mathbb{R} \quad$$

```
                            Im L(jω)
                               ^
                               |       Passive Region:
                               |       Re[L(jω)] >= 0
                               |
                               |          * L(jω)
              -1               |         /
              -+---------------+--------+----------> Re L(jω)
               |               |       /
               |               |      /
               |<--- |1+L| --->|     /
               |               |    /
               |               |   v
               |               |  Nyquist locus stays
               |               |  entirely in the RHP!
```

_(Geometric proof: For any passive loop $L(j\omega)$ residing in the right-half plane, the distance to the critical point $-1$ is always $|1 + L(j\omega)| \ge 1$)._

#### Why Passivity Guarantees $|S(j\omega)| \le 1$ Everywhere

Recall the definition of the Sensitivity Function: $$S(s) = \frac{1}{1 + L(s)} \implies |S(j\omega)| = \frac{1}{|1 + L(j\omega)|} \quad$$ In the complex plane, the denominator $|1 + L(j\omega)|$ is the Euclidean distance from the critical instability point $-1 + j0$ to the point $L(j\omega)$ on the Nyquist curve.

1. Because $L(j\omega)$ is constrained to the right-half plane ($\text{Re}[L(j\omega)] \ge 0$), the real part of $1 + L(j\omega)$ satisfies: $$\text{Re}[1 + L(j\omega)] = 1 + \text{Re}[L(j\omega)] \ge 1 \quad$$
2. Computing the magnitude: $$|1 + L(j\omega)| = \sqrt{\big(1 + \text{Re}[L(j\omega)]\big)^2 + \big(\text{Im}[L(j\omega)]\big)^2} \ge \sqrt{1^2 + 0} = 1 \quad$$
3. Taking the reciprocal directly yields: $$|S(j\omega)| = \frac{1}{|1 + L(j\omega)|} \le 1, \quad \forall \omega \in \mathbb{R} \quad$$
4. Consequently, the **peak sensitivity** satisfies: $$M_s = \max_{\omega} |S(j\omega)| \le 1 \quad$$

- **Design Consequence:** In a strictly passive feedback loop, feedback **never amplifies external disturbances or errors at any frequency** ($|S(j\omega)| \le 1$ everywhere). The loop possesses infinite gain margin, at least $90^\circ$ of phase margin, and does not experience resonant peaking. It represents the rare case where feedback operates without triggering the trade-offs described by the waterbed effect.

## 2. Peak Sensitivity $M_s$ and Stability Margin Geometry

### Revision Checklist

- [ ] **Relate peak sensitivity** $M_s = \max_\omega |S(j\omega)|$ to the stability margin $s_m = \min_\omega |1 + L(j\omega)|$ ($M_s = 1/s_m$).
- [ ] **Explain why $M_s \ge 1$** for any non-trivial, non-passive feedback system.
- [ ] **Identify the peak frequency** $\omega_{ms}$ and explain why closed-loop disturbance amplification is worst at $\omega_{ms}$.
- [ ] **State the practical target ranges** for $M_s$ ($1.3 \le M_s \le 2.0$, or $3\text{ dB}$ to $6\text{ dB}$).

---

### Core Concepts & Formulations

#### Peak Sensitivity as a Robustness Indicator

For general physical plants (which are non-passive due to actuators, sensors, computing delays, or right-half-plane singularities), the loop locus $L(j\omega)$ enters the left-half plane, passing near $-1$.

- **Maximum Sensitivity ($M_s$):** $$M_s = \max_{-\infty < \omega < +\infty} |S(j\omega)| = \frac{1}{\min_\omega |1 + L(j\omega)|} = \frac{1}{s_m} \quad$$ where $s_m$ is the shortest vector distance from the Nyquist plot to $-1$.
- **Physical Significance of $M_s$:**
    - If $M_s \approx 1$ ($0\text{ dB}$), the closed-loop system never amplifies disturbances by more than unity.
    - If $M_s \gg 2$ (e.g., $M_s = 5 \implies 14\text{ dB}$), the system amplifies measurement noise and load disturbances by a factor of 5 near the frequency $\omega_{ms}$, exhibiting low damping, large step overshoot, and high vulnerability to parameter uncertainty.
    - Control engineers target $M_s \in [1.3, 1.8]$ ($2.3\text{ dB}$ to $5.1\text{ dB}$) to ensure acceptable stability margins ($s_m \ge 0.55$).

```
       |   Error Attenuation Band       /     \     Unattenuated Region

```

## 3. Bode's Integral Formula & The "Waterbed Effect" (Stable Systems)

### Revision Checklist

- [ ] **State the roll-off assumption** required for Bode's integral formula ($\lim_{s \to \infty} s L(s) = 0$, relative degree $\ge 2$).
- [ ] **State Bode's Integral Formula** for an open-loop stable loop transfer function: $$\int_{0}^{\infty} \ln |S(j\omega)| , d\omega = 0 \quad$$
- [ ] **Explain the geometric meaning** of positive area ($\ln |S| > 0$) versus negative area ($\ln |S| < 0$).
- [ ] **State the physical meaning** of the "waterbed effect" (conservation of sensitivity volume).
- [ ] **Explain why pushing sensitivity down** at low frequencies forces sensitivity to pop up above unity elsewhere.

---

### Core Concepts & Formulations

#### Theorem: Bode's Integral Formula for Stable Systems

Let $S(s) = \frac{1}{1 + L(s)}$ be the sensitivity function of an internally stable feedback system. If the open-loop transfer function $L(s) = P(s)C(s)$ has a relative degree of at least 2 (such that $\lim_{s \to \infty} s L(s) = 0$), and has **no poles in the closed right-half complex plane** (open-loop stable), then:

$$\int_{0}^{\infty} \ln |S(j\omega)| , d\omega = \int_{0}^{\infty} \ln \frac{1}{|1 + L(j\omega)|} , d\omega = 0 \quad$$

_(Note: The integration is taken with respect to frequency $\omega$ on a **linear scale**, while sensitivity magnitude is evaluated on a natural logarithmic scale)._

#### Geometric and Physical Interpretation

Because $\ln(1) = 0$:

- When $|S(j\omega)| < 1$, $\ln |S(j\omega)| < 0$ (yielding a **negative area** below the zero line where disturbances are attenuated).
- When $|S(j\omega)| > 1$, $\ln |S(j\omega)| > 0$ (yielding a **positive area** above the zero line where disturbances are amplified).

Bode's theorem states that the total net area is conserved identically at zero: $$\text{Area Below Zero Line } (\ln |S| < 0) = \text{Area Above Zero Line } (\ln |S| > 0) \quad$$

```
     ln|S(jω)|
        ^
        |                               Area Above (ln|S| > 0):
        |                               Disturbance Amplification (|S| > 1)
        |                                    +--------+
        |                                   / :::::::  \
    0 --+----------------------------------+------------+-----------------> Frequency ω
        | \  ::::::::::::::::: /           ω_sc          \
        |  \  Negative Area   /                           \
        |   +----------------+                             +---> Asymptotic 0 dB
        |   Area Below (ln|S| < 0):
        |   Disturbance Attenuation (|S| < 1)
        v
                 Net Area Below = Net Area Above  (Total Integral = 0)
```

_(Graphical representation of Bode's Integral: The area of attenuation below zero must be balanced by an equal area of amplification above zero)._

#### The "Waterbed Effect"

Bode's integral acts as a fundamental law of conservation in feedback systems:

- **The Analogy:** Pushing down on one part of a waterbed causes another part to bulge upward.
- **The Engineering Compromise:** If an engineer increases controller gains to force $|S(j\omega)| \ll 1$ across a wider tracking bandwidth $[0, \omega_1]$, the negative area increases. To maintain the zero integral sum, **$|S(j\omega)|$ must exceed unity across an adjacent frequency band**, producing a sensitivity peak ($M_s > 1$).
- **Stein’s Dirt-Mound Analogy:** Gunter Stein compared control design to shoveling dirt on an uneven mound: you cannot remove the volume of dirt; you can only shovel it from one frequency range into another. A skilled designer moves the inevitable amplification peak into a benign frequency band where disturbance power and measurement noise are minimal.

## 4. Unstable Plants: The Generalized Bode Integral

### Revision Checklist

- [ ] **State the generalized Bode Integral Formula** for plants with open-loop right-half-plane poles $p_k$: $$\int_{0}^{\infty} \ln |S(j\omega)| , d\omega = \pi \sum_{p_k > 0} p_k \quad$$
- [ ] **Explain why the presence of RHP poles makes the waterbed effect strictly worse**.
- [ ] **State the exponential lower bound on peak sensitivity** $M_s$ when controlling an unstable plant over a finite bandwidth.
- [ ] **Explain why multiple or fast unstable poles** force high sensitivity and severe closed-loop fragility.

---

### Core Concepts & Formulations

#### Theorem: Generalized Bode Integral for Unstable Systems

Assume the closed-loop system is internally stabilized by feedback controller $C(s)$, with relative degree $\ge 2$. If the open-loop transfer function $L(s) = P(s)C(s)$ has $m$ unstable poles $p_1, p_2, \dots, p_m$ in the open right-half complex plane ($\text{Re}(p_k) > 0$), then:

$$\int_{0}^{\infty} \ln |S(j\omega)| , d\omega = \pi \sum_{k=1}^{m} \text{Re}(p_k) \quad$$

*(If an unstable pole is a complex conjugate pair $p$, $p_{i,j} = \sigma \pm j\omega_0$, their combined contribution to the right-hand sum is $\pi(\sigma + \sigma) = 2\pi\sigma$).*

#### Physical Meaning: The Price of Unstable Dynamics

Because the real parts of open-loop RHP poles are strictly positive ($\text{Re}(p_k) > 0$), the right-hand side of Bode's formula is **strictly positive**: $$\int_{0}^{\infty} \ln |S(j\omega)| , d\omega = \pi \sum_{k=1}^m p_k > 0 \quad$$

This leads to two consequences:

1. **Positive Area Dominance:** The positive area (where $|S| > 1$, error amplification) must exceed the negative area (where $|S| < 1$, error suppression) by an amount equal to $\pi \sum p_k$.
2. **The Penalty of Instability:** The feedback controller must "pay" for stabilizing an open-loop unstable mode by accepting larger sensitivity and degraded robustness in other frequency bands. Fast unstable poles (large positive $p_k$) impose a severe penalty, making tight disturbance rejection difficult to achieve.

#### Exponential Bound on Peak Sensitivity

Consider an open-loop plant with an unstable pole at $s = +p$ ($p > 0$). Suppose the designer requires good disturbance attenuation ($|S(j\omega)| \le \epsilon < 1$) over the operational bandwidth $\omega \in [0, \omega_1]$, and measurement noise prevents active feedback beyond the actuator bandwidth $\omega_a$ (such that $|S(j\omega)| \approx 1$ for $\omega \ge \omega_a$):

```
  |S(jω)|
     ^
  Ms +                         +---------------------+
     |                        /|                     |
     |                       / |                     |
     |                      /  |                     |
 1.0 +                     /   |                     +------- |S| = 1
     |                    /    |
     |                   /     |
   ε +------------------+      |
     0                 ω1     ωa                             Frequency ω
        Low-Sensitivity       Actuator Cutoff
```

_(Piecewise sensitivity model illustrating the exponential lower bound on $M_s$)._

Evaluating Bode's integral under this piecewise profile yields the lower bound on peak sensitivity: $$M_s \ge \exp\left( \frac{\pi p + \omega_1(1 - \epsilon)}{\omega_a - \omega_1} \right) \quad$$

- **Exponential Sensitivity Growth:** As the target tracking bandwidth $\omega_1$ approaches the actuator bandwidth limit $\omega_a$, the denominator $(\omega_a - \omega_1) \to 0$, causing $M_s \to \infty$ exponentially.
- **Minimum Actuator Bandwidth Requirement:** To maintain peak sensitivity within acceptable bounds ($M_s \le 2 \implies \ln M_s \approx 0.693$), the actuator bandwidth $\omega_a$ must be significantly larger than the open-loop unstable pole location: $$\omega_a \gg \pi p + \omega_1$$ If actuator bandwidth is insufficient, **stabilization is impossible without severe closed-loop resonant peaking and fragility**.

## 5. Mathematical Proof of Bode's Integral Formula

### Revision Checklist

- [ ] **Construct the closed integration contour** $\Gamma$ enclosing the entire RHP and indenting around open-loop unstable poles $p_k$.
- [ ] **Apply Cauchy’s Residue Theorem** to the analytic complex logarithm $\ln S(s)$ along $\Gamma$.
- [ ] **Evaluate the contour integral along the imaginary axis**: $$I_1 = -2j \int_{0}^{\infty} \ln |S(j\omega)| , d\omega \quad$$
- [ ] **Evaluate the semicircular indentations** around each open-loop pole $p_k$ to extract the residues $-2\pi j p_k$.
- [ ] **Show that the integral along the infinite outer arc vanishes** when $\lim_{s \to \infty} s L(s) = 0$.

---

### Step-by-Step Mathematical Derivation

#### 1. Integration Contour Setup

Consider the sensitivity function $S(s) = \frac{1}{1 + L(s)}$. Since the closed-loop system is internally stable, $1 + L(s)$ has no zeros in the closed right-half plane ($\text{Re}(s) \ge 0$), meaning $S(s)$ has no poles in the RHP. However, whenever the open-loop transfer function $L(s)$ has a pole at $s = p_k$ with $\text{Re}(p_k) > 0$, $L(p_k) \to \infty$, which causes the sensitivity function to vanish: $$S(p_k) = \frac{1}{1 + L(p_k)} = 0 \implies \ln S(p_k) \to -\infty \quad$$

Thus, the function $f(s) = \ln S(s)$ has isolated logarithmic branch points at every open-loop RHP pole $p_k$. To apply Cauchy's theorem, construct a counter-clockwise contour $\Gamma$ in the complex $s$-plane consisting of:

1. The imaginary axis from $s = -jR$ to $s = +jR$.
2. The infinite outer semicircular arc $s = R e^{j\theta}$ for $\theta \in [-\pi/2, +\pi/2]$ with $R \to \infty$.
3. Lateral cuts connecting the imaginary axis to small circles of radius $\epsilon \to 0$ enclosing each RHP pole $p_k$.

```
                 Contour Γ for Proving Bode's Integral Formula
                                     jω
                                     ^
                                 +jR |       Outer Arc: s = R e^(jθ)
                                     |    )  R -> ∞, θ: +90° -> -90°
                                     |     \
                                     |      \
                                     +----->--* pk (Open-loop pole detour)
                                     |<----- /
                                     |      /
                                     |     /
                                 -jR |    )
                                     +-------------------------> σ
```

_(Contour $\Gamma$ enclosing the right-half plane while detouring around isolated singularities at $s = p_k$)._

#### 2. Cauchy’s Integral Application

Because $f(s) = \ln S(s)$ is analytic everywhere inside and on $\Gamma$, Cauchy's Integral Theorem gives: $$\oint_{\Gamma} \ln S(s) , ds = 0 \quad$$

Splitting the closed contour integral into its constituent geometric segments: $$\int_{\text{Imaginary Axis}} \ln S(s) , ds + \int_{\text{Outer Arc}} \ln S(s) , ds + \sum_{k=1}^m \oint_{\text{Detour}(p_k)} \ln S(s) , ds = 0 \quad$$

#### 3. Imaginary Axis Segment ($s = j\omega$)

Along the imaginary axis, $s = j\omega$ and $ds = j , d\omega$: $$\int_{-j\infty}^{+j\infty} \ln S(s) , ds = j \int_{-\infty}^{+\infty} \ln S(j\omega) , d\omega = j \int_{-\infty}^{+\infty} \big( \ln |S(j\omega)| + j \angle S(j\omega) \big) , d\omega \quad$$ Because the magnitude $|S(j\omega)|$ is an even function of $\omega$ ($\ln |S(-j\omega)| = \ln |S(j\omega)|$) and the phase angle $\angle S(j\omega)$ is an odd function ($\angle S(-j\omega) = -\angle S(j\omega)$), the imaginary part integrates to zero, leaving: $$\int_{-j\infty}^{+j\infty} \ln S(s) , ds = 2j \int_{0}^{\infty} \ln |S(j\omega)| , d\omega \quad$$

#### 4. Infinite Semicircular Outer Arc ($R \to \infty$)

Along the outer arc, $s = R e^{j\theta}$ with $\theta \in [\pi/2, -\pi/2]$. Since relative degree $\ge 2$, $L(s) \approx \frac{K}{s^k}$ ($k \ge 2$) for large $s$, so $\lim_{s \to \infty} s L(s) = 0$. Using the Taylor series approximation $\ln(1 + x) \approx x$ for small $x$: $$\ln S(s) = \ln \frac{1}{1 + L(s)} = -\ln(1 + L(s)) \approx -L(s)$$ Evaluating along the outer semicircle: $$\left| \int_{\text{Outer Arc}} \ln S(s) , ds \right| \le \int_{-\pi/2}^{\pi/2} |L(R e^{j\theta})| R , d\theta \to 0 \quad \text{as } R \to \infty \quad$$

#### 5. Evaluation of Singular Pole Detours

For each isolated pole $p_k$, the forward and return paths along the lateral cut cancel out. Integrating counter-clockwise around the small circular contour enclosing $p_k$ via integration by parts yields: $$\oint \ln S(s) , ds = -2\pi j , p_k \quad$$

#### 6. Assembling the Terms

Substituting all evaluated segments into Cauchy’s equation: $$2j \int_{0}^{\infty} \ln |S(j\omega)| , d\omega - 2\pi j \sum_{k=1}^m p_k = 0$$ Dividing through by $2j$ yields Bode’s Integral Formula: $$\int_{0}^{\infty} \ln |S(j\omega)| , d\omega = \pi \sum_{k=1}^m p_k \quad$$

## 6. Fundamental Limits Imposed by RHP Zeros, Delays, and RHP Poles

### Revision Checklist

- [ ] **Explain why Right-Half-Plane (RHP) zeros** cannot be cancelled by a stabilizing controller.
- [ ] **State the Complementary Sensitivity integral formula** for open-loop RHP zeros $z_k$: $$\int_{0}^{\infty} \frac{\ln |T(j\omega)|}{\omega^2} , d\omega = \pi \sum_{z_k > 0} \frac{1}{z_k} \quad$$
- [ ] **Apply the Maximum Modulus Principle** to establish interpolation constraints: $S(z) = 1$ and $T(p) = 1$.
- [ ] **Derive the sensitivity peak bound** for a plant with both an RHP pole $p$ and an RHP zero $z$: $$M_s \ge \left| \frac{z + p}{z - p} \right| \quad$$
- [ ] **Formulate crossover frequency bounds** imposed by non-minimum-phase zeros ($\omega_{sc} < z$) and time delays ($\omega_{gc} \tau \le \phi_{ap}$).

---

### Core Concepts & Formulations

#### 1. Right-Half-Plane (RHP) Zeros and Complementary Sensitivity

A zero in the right-half plane ($s = +z_0, ; z_0 > 0$) introduces phase lag without altering magnitude, making the system **non-minimum-phase**.

- **Bode’s Integral for Complementary Sensitivity:** An integral formula dual to Bode's sensitivity integral applies to $T(s)$: $$\int_{0}^{\infty} \frac{\ln |T(j\omega)|}{\omega^2} , d\omega = \pi \sum_{k=1}^{\ell} \frac{1}{z_k} \quad$$ where $z_k$ are the RHP zeros of the open-loop transfer function.
- **Physical Implication:** Slow RHP zeros (small $z_k$) yield large values of $1/z_k$, creating a large positive area under $\ln |T|/\omega^2$. Because accurate command tracking requires $T \approx 1$ ($\ln |T| \approx 0$) at low frequencies, **slow RHP zeros force significant peak overshoot or amplification in complementary sensitivity ($M_t > 1$)**.

#### 2. Maximum Modulus Principle & Interpolation Constraints

For an internally stable feedback loop, the closed-loop transfer functions must satisfy the following algebraic interpolation conditions:

1. **At an open-loop RHP zero $z$ ($P(z) = 0 \implies L(z) = 0$):** $$S(z) = \frac{1}{1 + L(z)} = 1, \quad T(z) = \frac{L(z)}{1 + L(z)} = 0$$
2. **At an open-loop RHP pole $p$ ($P(p) \to \infty \implies L(p) \to \infty$):** $$S(p) = 0, \quad T(p) = 1$$

By the **Maximum Modulus Principle**, the maximum of an analytic function in the right-half plane must occur on its boundary (the imaginary axis $j\omega$). Therefore: $$M_s = \max_{\omega} |S(j\omega)| \ge |S(z)| = 1, \quad M_t = \max_{\omega} |T(j\omega)| \ge |T(p)| = 1 \quad$$

#### 3. Combined RHP Pole and Zero Interaction

If a physical plant possesses **both an unstable pole $p$ and a non-minimum-phase zero $z$** in the right-half plane, the all-pass factor relating them produces a strict bound on peak sensitivity:

$$M_s \ge \left| \frac{z + p}{z - p} \right|, \quad M_t \ge \left| \frac{z + p}{z - p} \right| \quad$$

```
   Sensitivity Peak Lower Bound Ms
         ^
         |      |z + p|
         | Ms >= -------
         |      |z - p|
         |
         |                     As p -> z, Ms -> ∞!
         |                     Severe Control Limitation!
         |                         |
         |                        /
     1.0 +-----------------------+--------------------> Ratio p / z
         0                       1
```

_(Sensitivity peaking as an RHP pole $p$ approaches an RHP zero $z$)._

- **The Pole-Zero Proximity Disaster:** If an unstable pole is located close to a non-minimum-phase zero ($p \approx z$), the denominator $|z - p| \to 0$, forcing **$M_s \to \infty$ and stability margin $s_m \to 0$**. Such plants are virtually impossible to control robustly.

#### 4. Bandwidth and Crossover Limits Summary

|Plant Limitation|Underlying Mechanism|Strict Frequency-Domain Constraint|Practical Design Rule|
|:--|:--|:--|:--|
|**Real RHP Zero ($z$)**|Inherent phase lag; initial undershoot in time response.|$\omega_{sc} \le z \sqrt{\frac{M_s - 1}{M_s + 1}}$|Keep bandwidth well below the zero: $\omega_{gc} < 0.5 z$.|
|**Pure Time Delay ($\tau$)**|Linear phase drop $\angle(e^{-j\omega\tau}) = -\omega\tau$ with no gain attenuation.|$\omega_{gc} \tau \le \phi_{ap} \quad (\phi_{ap} \approx 45^\circ - 60^\circ)$|Limit crossover frequency: $\omega_{gc} < \frac{1}{\tau}$.|
|**Real RHP Pole ($p$)**|Inherent dynamic divergence requiring fast stabilizing action.|$\omega_{tc} \ge p \sqrt{\frac{M_t + 1}{M_t - 1}}$|Bandwidth must exceed the pole: $\omega_{gc} > 2 p$.|
|**Combined RHP Pole & Zero ($p, z$)**|Conflicting bandwidth requirements: $\omega_{gc}$ must be $> 2p$ and $< 0.5z$.|$M_s \ge \left\lvert \dfrac{z + p}{z - p} \right\rvert$|Avoid designs with $p \approx z$; $M_s \to \infty$ as the pole approaches the zero.|

### Core Concepts & Engineering Case Study

#### Background: The Grumman X-29 Forward-Swept Wing Demonstrator

The Grumman X-29 used forward-swept wings and active canard surfaces to achieve extreme pitch agility, resulting in a **highly unstable airframe** with an open-loop unstable pole at roughly $p \approx 6\text{ rad/s}$ ($~1\text{ Hz}$).

```
                 Canard Deflection (u)               Aerodynamic Pitch (y)
                 ---->[ Actuator (ωa) ]---->[ Airframe (p = 6 rad/s) ]---->
```

_(The X-29 pitch control channel: Actuator hydraulic rate limits constrain the loop bandwidth relative to the open-loop unstable pole)._

#### Sensitivity Analysis via Bode's Integral

Using Stein's piecewise sensitivity model with open-loop unstable pole $p$: $$\int_{0}^{\infty} \ln |S(j\omega)| , d\omega = \pi p \quad$$ Assuming good disturbance rejection ($|S| \le \epsilon$) up to tracking frequency $\omega_1$, bounded peak sensitivity $M_s$ across $[\omega_1, \omega_a]$, and actuator roll-off ($|S| \approx 1$) above hydraulic cutoff frequency $\omega_a$, integration yields: $$\ln M_s = \frac{\pi p + \omega_1}{\omega_a} \implies M_s = \exp\left( \frac{\pi p + \omega_1}{\omega_a} \right) \quad$$

- **Numerical Evaluation:**
    - For the X-29 with $p = 6\text{ rad/s}$ and desired control bandwidth $\omega_1 = 3\text{ rad/s}$: $$\pi p + \omega_1 = \pi(6) + 3 \approx 18.85 + 3 = 21.85\text{ rad/s}$$
    - If hydraulic surface actuators have a bandwidth of $\omega_a = 30\text{ rad/s}$: $$M_s = \exp\left( \frac{21.85}{30} \right) = \exp(0.728) \approx 2.07 \quad (\text{acceptable stability margin: } s_m \approx 0.48)$$
    - If actuator response drops (due to thermal fade, pressure drop, or rate limits) to $\omega_a = 15\text{ rad/s}$: $$M_s = \exp\left( \frac{21.85}{15} \right) = \exp(1.457) \approx 4.29 \quad (\text{fragile margin: } s_m \approx 0.23)$$
- **The Lesson of "Respect the Unstable":** When controlling open-loop unstable systems, **feedback requires adequate actuator authority and bandwidth**. If an actuator saturates in velocity or angle, effective loop gain collapses, moving $\omega_a$ inward and causing $M_s \to \infty$, leading to immediate loss of control.

| :---------------------------------- | :---------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------- |
| **Passivity (Frequency Domain)** | $\text{Re}[L(j\omega)] \ge 0, \quad \forall \omega$ | Nyquist plot stays in RHP, guaranteeing $\lvert S(j\omega)\rvert \le 1$. |
| **Bode Integral (Stable Plants)** | $\int_{0}^{\infty} \ln \lvert S(j\omega)\rvert \, d\omega = 0$ | Waterbed effect: sensitivity attenuation is balanced by an equal area of amplification. |
| **Bode Integral (Unstable Plants)** | $\int_{0}^{\infty} \ln \lvert S(j\omega)\rvert \, d\omega = \pi \sum_{p_k > 0} p_k$ | Unstable poles worsen the waterbed: amplification exceeds attenuation by $\pi \sum p_k$. |
| **Exponential Peaking Bound**       | $M_s \ge \exp\left(\frac{\pi p + \omega_1}{\omega_a - \omega_1}\right) \quad$ | As control bandwidth approaches actuator cutoff, sensitivity peaks exponentially.          |
| **Maximum Modulus Condition**       | $S(z) = 1, \quad T(p) = 1 \implies M_s, M_t \ge 1 \quad$                      | Right-half-plane singularities act as interpolation obstacles for sensitivity functions.   |
| **RHP Pole-Zero Interaction** | $M_s \ge \left\lvert \dfrac{z + p}{z - p} \right\rvert$ | An RHP pole near an RHP zero forces severe sensitivity peaking ($M_s \to \infty$ as $p \to z$). |
| **RHP Zero Bandwidth Limit**        | $\omega_{sc} \le z \sqrt{\frac{M_s - 1}{M_s + 1}} \quad$                      | Non-minimum-phase zeros place an upper bound on achievable closed-loop bandwidth.          |
| **Time-Delay Limit**                | $\omega_{gc} \tau \le \phi_{ap} \quad$                                        | Linear phase lag from transport delays limits crossover frequency: $\omega_{gc} < 1/\tau$. |

## 9. MATLAB Script: Demonstrating the Waterbed Effect & Bode's Integral

```
%% ECE4132 Week 12: Waterbed Effect and Bode Integral Verification
clear; clc; close all;

% 1. Define Open-Loop Stable Plant
s = tf('s');
P = 1 / ((s + 1)*(s + 2));          % Relative degree = 2 (lim s*L = 0)

% 2. Compare Two Controllers: Moderate vs. Aggressive Integral Action
C_mod = 2 + 1/s;                    % Moderate PI controller
C_agg = 15 + 25/s;                  % Aggressive PI controller

L_mod = P * C_mod;
L_agg = P * C_agg;

% 3. Closed-Loop Sensitivity Functions
S_mod = feedback(1, L_mod);
S_agg = feedback(1, L_agg);

% 4. Frequency Grid for Integration (Linear scale for Bode's Integral)
w = linspace(0.001, 100, 50000);   % Linear frequency vector
[mag_mod, ~] = bode(S_mod, w);
[mag_agg, ~] = bode(S_agg, w);

log_S_mod = log(squeeze(mag_mod));  % Natural logarithm ln|S(jω)|
log_S_agg = log(squeeze(mag_agg));

% 5. Numerical Trapezoidal Integration of Bode's Integral
integral_mod = trapz(w, log_S_mod);
integral_agg = trapz(w, log_S_agg);

fprintf('=== Numerical Verification of Bode Integral ===\n');
fprintf('Theoretical Area for Stable Plant: 0.000\n');
fprintf('Integrated Area (Moderate PI):    %.4f\n', integral_mod);
fprintf('Integrated Area (Aggressive PI):  %.4f\n', integral_agg);

% 6. Plot Sensitivity Curves Illustrating the Waterbed Effect
figure('Name', 'The Waterbed Effect in Sensitivity');
plot(w, log_S_mod, 'b', 'LineWidth', 1.8); hold on;
plot(w, log_S_agg, 'r--', 'LineWidth', 1.8);
yline(0, 'k-', 'LineWidth', 1);
xlim(); ylim([-4, 1.5]);
grid on;
xlabel('Frequency \omega [rad/s] (Linear Scale)');
ylabel('ln |S(j\omega)|');
title('Waterbed Effect: Deeper Low-Frequency Attenuation Forces a Higher Peak M_s');
legend('Moderate Control (Lower M_s)', 'Aggressive Control (High M_s Peak)', '|S| = 1 Line');

% Peak Sensitivity Comparisons
Ms_mod = norm(S_mod, Inf);
Ms_agg = norm(S_agg, Inf);
fprintf('\nPeak Sensitivity Ms (Moderate): %.2f (%.2f dB)\n', Ms_mod, 20*log10(Ms_mod));
fprintf('Peak Sensitivity Ms (Aggressive): %.2f (%.2f dB)\n', Ms_agg, 20*log10(Ms_agg));
```
